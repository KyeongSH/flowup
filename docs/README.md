{% endhint %}

## 문서 표기 규칙

| 표기 | 의미 |
| --- | --- |
| 🔴 빨간 박스 (danger) | **필수** — 반드시 지켜야 하는 사항 |
| 🟡 노란 박스 (warning) | **주의** — 실수하기 쉬운 사항 |
| 🔵 파란 박스 (info) | 🖼️ 화면 캡처 삽입 위치 / 참고 |
| 🟢 초록 박스 (success) | **CHECK** — 확인 목록 |
| `담당자 확인 필요` | 실제 화면 확인 후 확정이 필요한 항목 |
