# 매뉴얼 확정 절차

본 문서는 매뉴얼 골격(v0.9)입니다. 각 화면 캡처 삽입 위치는 🖼️ 파란 박스로 표시되어 있으며, 실제 관리자 사이트(`admin.ezengn.flowup.co.kr`)에서 캡처한 이미지를 해당 위치에 삽입한 뒤 **v1.0**으로 확정합니다.

## 진행 순서

1. 담당자가 관리자 사이트에 로그인하여 매뉴얼에 표시된 각 화면(그림 번호별)을 순서대로 캡처합니다.
2. 캡처 이미지에 **빨간 박스·파란 박스·번호 표시**를 편집하고, 학생명·연락처·이메일 등 **개인정보는 모자이크** 처리합니다.
3. 이미지를 `docs/.gitbook/assets/` 폴더에 `fig-4-1.png` 형식으로 저장합니다.
4. 매뉴얼의 `[그림 X-X 삽입 위치]` 박스를 아래처럼 이미지로 교체합니다.
5. 각 화면 아래의 **진행 순서·주의사항**을 실제 화면 기준으로 보완합니다.

## 이미지 삽입 예시

교체 전:

```markdown
{% hint style="info" %}
🖼️ **[그림 4-1 삽입 위치] 전체 강의 목록 화면**<br>...
{% endhint %}
```

교체 후:

```markdown
<figure><img src="../.gitbook/assets/fig-4-1.png" alt="전체 강의 목록 화면"><figcaption><p>그림 4-1. 전체 강의 목록 화면</p></figcaption></figure>
```

{% hint style="danger" %}
**필수** 개인정보가 포함된 원본 캡처는 절대 저장소에 커밋하지 않습니다.
{% endhint %}
