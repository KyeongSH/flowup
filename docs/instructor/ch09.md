# 9장. 수업 진행 체크리스트

## 9.1 수업 전날 체크리스트

- [ ] 수업자료 등록 완료
- [ ] Zoom 링크(사전 공유) 확인
- [ ] 수업 전날 공지 게시
- [ ] 실습 환경 사전 안내

## 9.2 수업 당일 체크리스트

- [ ] Zoom 녹화 설정 확인 (시작 전 필수)
- [ ] 참여자(출석) 확인
- [ ] 수업 마무리 시 질의응답 안내
- [ ] 과제·다음 수업 안내

## 9.3 수업 종료 후 체크리스트

- [ ] Zoom 녹화 처리 완료 확인 (Zoom 클라우드)
- [ ] 녹화영상 콘텐츠 등록
- [ ] 수업자료 추가 등록 (필요 시)
- [ ] 커뮤니티 질문 응답

## 9.4 종강 전 체크리스트

- [ ] 전체 회차 녹화영상 등록 여부 확인
- [ ] 수업자료 누락 없음 확인
- [ ] 커뮤니티 미답변 질문 처리
- [ ] 운영 담당자에게 종강 알림
