# 2장. 로그인 및 기본 화면

## 2.1 로그인

1. 웹 브라우저에서 `https://admin.ezengn.flowup.co.kr/` 에 접속합니다.
2. 운영팀에서 발급받은 아이디·비밀번호를 입력합니다.
3. '로그인' 버튼을 선택합니다.

{% hint style="info" %}
🖼️ **[그림 2-1 삽입 위치] 로그인 화면**<br>아이디·비밀번호 입력창 · 로그인 버튼 강조
{% endhint %}

## 2.2 로그인 후 기본 화면

강사 계정으로 로그인하면 담당 과정 중심의 화면이 표시됩니다. 관리자 대시보드의 전체 통계가 아닌, **담당 클래스룸으로 바로 이동할 수 있는 영역**이 제공됩니다. `실제 화면 확인 필요`

{% hint style="info" %}
🖼️ **[그림 2-2 삽입 위치] 강사 로그인 후 기본 화면**<br>담당 과정 리스트 · 클래스룸 이동 버튼 영역
{% endhint %}

{% hint style="warning" %}
**주의** 일정 시간 미사용 시 자동 로그아웃되므로, 수업자료·게시물 작성 중에는 **수시로 저장**합니다.
{% endhint %}
