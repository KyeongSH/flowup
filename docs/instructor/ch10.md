# 10장. 오류 대응 및 자주 묻는 질문

## 10.1 자주 발생하는 오류

| 증상 | 확인 방법 | 해결 방법 | 문의 대상 |
| --- | --- | --- | --- |
| 담당 과정이 안 보임 | 배정 여부 확인 | 운영 담당자에게 배정 요청 | 운영 담당자 |
| 클래스룸 접속 불가 | 과정 배정 여부 | 배정 확인 후 재접속 | 운영 담당자 |
| 수업자료 업로드 실패 | 파일 크기·형식 확인 | 파일 압축 또는 분할 | 운영 담당자 |
| Zoom 링크 접근 불가(학생 문의) | 비밀번호 포함 링크 여부 | 링크 재발행 후 등록 갱신 | 본인 처리 |
| 공지 등록 후 학생이 못 봄 | 등록 상태·게시 기간 확인 | 재등록·기간 수정 | 본인 처리 |

## 10.2 자주 묻는 질문 (FAQ)

### Q1. 여러 과정을 담당하는 경우 어떻게 전환하나요?

담당 과정 목록으로 돌아가서 다른 과정을 선택합니다. 로그아웃할 필요는 없습니다.

### Q2. 수업자료를 잘못 올렸어요. 삭제해도 되나요?

수업 전이라면 삭제 후 재등록해도 무방합니다. 이미 훈련생이 열람한 경우, 삭제 대신 '수정'으로 파일을 교체하고 공지로 안내합니다.

### Q3. Zoom 녹화영상은 언제까지 등록해야 하나요?

운영 규정에 따라 다르지만, 일반적으로 **수업 종료 후 24~48시간 이내** 등록을 권장합니다. 세부 기준은 운영 담당자에게 확인합니다.

### Q4. 훈련생 개인 문의는 어디로 응답해야 하나요?

공개적으로 답변해도 될 내용은 커뮤니티에, 개인정보가 포함된 경우 **1:1 채널 또는 이메일**을 사용합니다. `1:1 채널 지원 여부 확인 필요`

### Q5. 강의 계획을 변경했을 때 어떻게 안내하나요?

공지사항에 등록하고, 필요 시 수업자료 목차도 함께 수정합니다. 큰 변경은 운영 담당자에게 사전 협의합니다.

### Q6. 학생이 로그인이 안 된다고 문의합니다.

강사 계정에서는 학생 계정 문제를 직접 해결할 수 없습니다. **운영/행정 담당자에게 전달**합니다.

### Q7. 저작권이 있는 자료를 수업에서 소개하고 싶습니다.

업로드 대신 **공식 출처 링크**를 등록하고, 수업 중 화면 공유 시에도 짧게 인용하고 출처를 명확히 표기합니다.

### Q8. 종강 후에도 클래스룸에 접근할 수 있나요?

일반적으로 종료 과정도 조회는 가능하지만 편집이 제한될 수 있습니다. `정확한 정책은 담당자 확인 필요`
