# 7장. Zoom · YouTube 콘텐츠 등록

## 7.1 Zoom 녹화영상 등록

#### 사전 준비

- Zoom 클라우드에서 녹화 파일이 정상 처리됐는지 확인합니다.
- '공유' → **비밀번호 포함 링크**를 복사합니다.

#### 진행 순서

1. 클래스룸의 '콘텐츠' 탭을 선택합니다.
2. '+ 콘텐츠 등록' 버튼을 선택합니다.
3. 유형에서 'Zoom 녹화영상'을 선택합니다.
4. 제목을 입력합니다. (예: "1주차 2일 · HTML 기본 실습 · 녹화본")
5. Zoom 공유 링크를 붙여넣습니다.
6. '등록' 버튼을 선택합니다.
7. 등록 후 **시크릿 창에서 링크를 열어 정상 재생되는지 반드시 확인**합니다.

{% hint style="info" %}
🖼️ **[그림 7-1 삽입 위치] Zoom 녹화영상 등록 화면**<br>유형 선택 · 제목 · 링크 · 등록 버튼 강조
{% endhint %}

{% hint style="warning" %}
**주의**

- 비밀번호 없는 링크는 **훈련생이 열람할 수 없습니다**.
- Zoom 클라우드는 저장기간 제한이 있으므로, 중요한 회차는 **별도 다운로드하여 백업**합니다.
- 등록한 링크가 만료된 경우, 항목을 삭제하지 말고 '수정'으로 갱신합니다.
{% endhint %}

## 7.2 YouTube 영상 등록

1. YouTube 영상 페이지에서 '공유' → URL을 복사합니다.
2. 콘텐츠 등록 화면에서 유형 'YouTube'를 선택합니다.
3. 제목과 URL을 입력합니다.
4. '등록' 버튼을 선택합니다.

## 7.3 외부 링크 등록

참고 사이트·문서 링크를 등록할 수 있습니다. 등록 후 **링크가 실제로 열리는지 반드시 확인**합니다. 유료·회원 전용 콘텐츠 링크는 등록에 부적합할 수 있습니다.
