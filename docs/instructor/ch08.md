# 8장. 커뮤니티 활동 관리

## 8.1 커뮤니티 채널 구조

과정별로 자유게시판·질문답변·자료실 등 여러 채널이 구성될 수 있습니다. 채널 구성은 **운영 담당자와 사전 협의**합니다.

## 8.2 게시물 작성

1. 클래스룸의 '커뮤니티' 탭을 선택합니다.
2. 게시할 채널을 선택합니다.
3. '+ 새 글' 버튼을 선택합니다.
4. 제목과 내용을 입력합니다.
5. '등록' 버튼을 선택합니다.

## 8.3 훈련생 질문 응대

{% hint style="success" %}
**권장**

- 질문 게시물은 **24시간 이내 응답**을 권장합니다.
- 수업 시간 외 문의는 답변 시점을 예고합니다. (예: "내일 오전 답변 드리겠습니다")
- 동일 질문이 반복될 경우 공지사항으로 승격합니다.
{% endhint %}

## 8.4 게시물 수정·삭제

{% hint style="danger" %}
**필수** 삭제된 게시물은 **복구가 불가**합니다. 학생의 게시물을 삭제하기 전에 반드시 삭제 사유를 확인하고, 필요 시 학생에게 사전 안내합니다.
{% endhint %}
