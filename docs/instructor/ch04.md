# 4장. 클래스룸 운영

## 4.1 클래스룸 접속

1. 담당 과정 목록에서 대상 과정을 선택합니다.
2. '클래스룸 이동' 버튼을 선택합니다.
3. 클래스룸 메인 화면이 표시됩니다.

{% hint style="info" %}
🖼️ **[그림 4-1 삽입 위치] 클래스룸 메인 화면**<br>공지 · 커뮤니티 · 수업자료 · 콘텐츠 · 참여자 탭 위치 강조
{% endhint %}

## 4.2 클래스룸 기본 구성

| 영역 | 용도 | 사용 빈도 |
| --- | --- | --- |
| 공지사항 | 수업 안내, 중요 공지 | 수업 전후 |
| 커뮤니티 | 자유 소통, 질문/답변 | 매일 |
| 수업자료 | PPT·PDF·실습 파일 공유 | 수업일 |
| 콘텐츠 | Zoom 녹화영상·YouTube·외부 링크 | 수업 후 |
| 참여자 | 수강생·공동 강사 확인 | 수시 |

## 4.3 참여자 확인

참여자 탭에서 현재 수강 중인 훈련생 목록을 확인합니다. 명단이 실제 등록인원과 일치하지 않는 경우 **운영 담당자에게 즉시 문의**합니다.
