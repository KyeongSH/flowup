# 5장. 공지사항 등록

#### 기능 목적

수업 일정 변경, 과제 안내, 중요 안내를 훈련생 전체에게 전달합니다.

#### 접근 경로

> 📍 **접근 경로:** 클래스룸 → 공지 탭 → '+ 새 공지'

#### 진행 순서

1. 클래스룸에서 '공지' 탭을 선택합니다.
2. '+ 새 공지' 버튼을 선택합니다.
3. 제목과 내용을 입력합니다.
4. 중요 공지 여부·게시 기간을 설정합니다. `옵션 확인 필요`
5. '등록' 버튼을 선택합니다.
6. 목록에서 정상 등록 여부를 확인합니다.

{% hint style="info" %}
🖼️ **[그림 5-1 삽입 위치] 공지사항 등록 화면**<br>**① 제목 입력** → **② 내용 입력** → **③ 등록 버튼**
{% endhint %}

#### 주의사항

{% hint style="warning" %}
**주의**

- 공지 삭제 후에는 **복구가 어려우므로** 내용을 다시 확인 후 삭제합니다.
- 학생 개인정보(이름·연락처)는 공지에 포함하지 않습니다.
- 외부 링크 삽입 시 **안전한 링크**인지 확인합니다.
{% endhint %}
