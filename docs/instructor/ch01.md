# 1장. 시작하기 전에

## 1.1 강사 계정의 권한 범위

강사 계정은 **본인이 담당하는 과정의 클래스룸에만 접근**할 수 있습니다. 다른 과정 및 학생·강사 관리 기능은 사용할 수 없습니다.

## 1.2 강사의 주요 업무

| 업무 | 주요 활동 | 주기 |
| --- | --- | --- |
| 수업 준비 | 수업자료 등록, 사전 공지 작성 | 수업 전일 |
| 수업 진행 | Zoom 진행, 출결 확인 | 매 수업 |
| 수업 종료 후 | 녹화영상·자료 등록, 질의응답 | 수업 종료 후 |
| 주간 마감 | 주간 자료 정리, 미제출 확인 | 주 1회 |
| 과정 종료 | 최종 자료 확인, 미완 항목 정리 | 종강 전 |

{% hint style="danger" %}
**필수** 학생의 개인정보(이름·연락처·이메일 등)를 **외부에 공유하거나 SNS·개인 저장소에 저장하지 않습니다**. 캡처·문서 공유 시 반드시 마스킹합니다.
{% endhint %}
