# 3장. 담당 과정 확인

## 3.1 담당 과정 목록 조회

1. 좌측 메뉴 또는 대시보드에서 '담당 과정' 영역을 선택합니다. `메뉴명 확인 필요`
2. 표시된 과정 목록에서 훈련기간·회차·상태를 확인합니다.
3. 수업을 진행할 과정을 선택하여 클래스룸으로 이동합니다.

## 3.2 과정 정보 확인 항목

- 과정명 및 회차
- 훈련기간
- 등록인원
- 공동 담당 강사(있는 경우)
- 과정 상태(모집 중 / 훈련 중 / 종료)

{% hint style="info" %}
**참고** 담당 과정이 목록에 보이지 않는 경우, **운영 담당자에게 담당 과정 배정 여부를 확인**합니다. 강사 계정에 과정이 배정되지 않으면 클래스룸에 접근할 수 없습니다.
{% endhint %}
