# 6장. Zoom 수업 참여 · 녹화영상 시청

## 6.1 실시간 Zoom 수업 참여

1. 수업 시작 시간 전 공지 또는 콘텐츠 영역에서 **Zoom 링크**를 확인합니다.
2. Zoom 링크를 선택합니다.
3. Zoom 앱이 실행되면 **본인 이름**으로 접속합니다. (닉네임·별명 사용 금지)
4. 수업 시작 시간에 맞춰 입장합니다.

{% hint style="warning" %}
**주의**

- Zoom 접속 시 **본인 이름(실명)**으로 설정합니다. 출석 확인이 어려울 수 있습니다.
- 수업 중 **무단 녹화·화면 캡처·외부 공유는 금지**됩니다.
- 마이크·카메라 설정은 강사의 안내를 따릅니다.
{% endhint %}

## 6.2 녹화영상 시청 (결석 · 복습)

1. 클래스룸의 '콘텐츠' 탭을 선택합니다.
2. 시청할 회차의 Zoom 녹화영상을 선택합니다.
3. Zoom 클라우드 재생 페이지가 열립니다.
4. 수업 자료에 안내된 **비밀번호를 입력**합니다. (필요 시)

{% hint style="info" %}
**참고** 녹화영상은 Zoom 클라우드 저장기간이 만료되면 접근이 어려울 수 있습니다. 결석 시 **가능한 빨리 시청**하는 것을 권장합니다.
{% endhint %}
