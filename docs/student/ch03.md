# 3장. 내 과정(클래스룸) 접속

## 3.1 로그인 후 첫 화면

로그인하면 본인이 수강 중인 과정 목록이 표시됩니다. 여러 과정을 수강 중이라면 접속할 과정을 선택합니다.

{% hint style="info" %}
🖼️ **[그림 3-1 삽입 위치] 훈련생 첫 화면 · 수강 과정 목록**<br>본인 수강 과정 카드 · 클래스룸 입장 버튼 강조
{% endhint %}

## 3.2 클래스룸 이동

1. 수강 과정 목록에서 대상 과정을 선택합니다.
2. '클래스룸' 또는 '입장' 버튼을 선택합니다. `버튼명 확인 필요`
3. 과정별 클래스룸 화면이 표시됩니다.

## 3.3 클래스룸 구성 안내

| 영역 | 확인할 내용 |
| --- | --- |
| 공지사항 | 매일 접속 시 가장 먼저 확인 |
| 수업자료 | 당일·이전 수업 자료 다운로드 |
| 콘텐츠 | Zoom 녹화영상 시청, 참고 링크 열람 |
| 커뮤니티 | 공지·질문·자유 소통 |
