# 1장. 플로우업 소개

플로우업(FLOWUP)은 이젠아카데미의 **온라인 학습 플랫폼**입니다. 훈련 기간 동안 공지사항 확인, 수업자료 다운로드, Zoom 수업 참여, 커뮤니티 활동을 이 하나의 시스템에서 이용할 수 있습니다.

## 1.1 훈련생이 사용하는 주요 기능

| 기능 | 이용 목적 |
| --- | --- |
| 공지사항 | 수업 일정, 과제 안내, 중요 공지 확인 |
| 수업자료 | 강의 PPT · 실습 파일 · 참고 자료 다운로드 |
| Zoom 수업 | 실시간 수업 참여, 결석 시 녹화영상 시청 |
| 커뮤니티 | 질문, 동료와 소통, 학습 후기 공유 |

## 1.2 이용 시 주의사항

{% hint style="danger" %}
**필수**

- 본인 계정은 **타인과 공유하지 않습니다**. 대리 출석·대리 수강은 불이익 대상입니다.
- 수업자료·녹화영상은 **본인 학습 목적**으로만 사용하며, 외부에 배포하지 않습니다.
- 커뮤니티에 다른 훈련생의 개인정보나 사생활을 게시하지 않습니다.
{% endhint %}
