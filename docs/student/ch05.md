# 5장. 수업자료 다운로드

#### 이용 방법

1. 클래스룸에서 '수업자료' 탭을 선택합니다.
2. 수업 회차·주제로 목록을 확인합니다.
3. 필요한 자료의 제목을 선택합니다.
4. 첨부파일 또는 링크를 다운로드하거나 엽니다.

{% hint style="info" %}
🖼️ **[그림 5-1 삽입 위치] 수업자료 목록 화면**<br>자료 리스트 · 다운로드 버튼 · 파일 형식 아이콘
{% endhint %}

{% hint style="danger" %}
**필수**

- 다운로드한 자료는 **본인 학습 목적**으로만 사용합니다.
- SNS · 커뮤니티 · 외부 사이트에 **재배포하지 않습니다**.
- 강사·이젠아카데미의 저작권을 존중합니다.
{% endhint %}
