# 2장. 로그인 방법

## 2.1 접속 주소

웹 브라우저(Chrome 권장)에서 아래 주소로 접속합니다.

{% hint style="info" %}
**주소** `https://ezengn.flowup.co.kr/` ※ 관리자용(admin) 주소와 다를 수 있으며, **정확한 훈련생 접속 주소는 담당 운영 매니저에게 확인**하세요. `확인 필요`
{% endhint %}

## 2.2 로그인 순서

1. 접속 주소에 들어갑니다.
2. 이젠아카데미에서 발급받은 **아이디와 비밀번호**를 입력합니다.
3. '로그인' 버튼을 선택합니다.
4. 최초 로그인 시 비밀번호 변경 안내가 나오면 새 비밀번호로 변경합니다. `확인 필요`

{% hint style="info" %}
🖼️ **[그림 2-1 삽입 위치] 훈련생 로그인 화면**<br>아이디·비밀번호 입력창 · 로그인 버튼 강조 표시
{% endhint %}

## 2.3 비밀번호를 잊어버렸을 때

1. 로그인 화면의 '비밀번호 찾기'를 선택합니다. `지원 여부 확인 필요`
2. 안내에 따라 본인 확인을 진행합니다.
3. 비밀번호가 재발급되지 않는 경우 **담당 운영 매니저에게 문의**합니다.
