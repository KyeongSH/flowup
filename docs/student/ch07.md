# 7장. 커뮤니티에 글쓰기 · 질문하기

## 7.1 게시물 작성

1. 클래스룸의 '커뮤니티' 탭을 선택합니다.
2. 작성할 채널(자유게시판·질문답변 등)을 선택합니다.
3. '+ 새 글' 버튼을 선택합니다.
4. 제목과 내용을 입력합니다.
5. '등록' 버튼을 선택합니다.

## 7.2 좋은 질문 작성 팁

{% hint style="success" %}
**TIPS**

- **제목에 주제를 명확히** 씁니다. 예: "1주차 실습 · CSS Flexbox 정렬 질문"
- 본문에 **시도한 방법**과 **발생한 오류·결과**를 함께 적습니다.
- 오류 메시지·화면 캡처를 첨부하면 빠른 답변을 받을 수 있습니다.
- 본인·타인의 **개인정보(이름·연락처·계정)**는 포함하지 않습니다.
{% endhint %}

{% hint style="info" %}
🖼️ **[그림 7-1 삽입 위치] 커뮤니티 글쓰기 화면**<br>채널 선택 · 제목 · 본문 · 등록 버튼 강조
{% endhint %}

## 7.3 댓글·답변 확인

본인이 작성한 글에 답변이 달리면 알림 또는 목록에서 확인할 수 있습니다. `알림 지원 여부 확인 필요`

## 7.4 게시물 수정·삭제

본인 게시물은 상세 화면의 '수정'·'삭제' 버튼으로 관리할 수 있습니다. **삭제된 글은 복구할 수 없으므로** 신중히 선택합니다.
