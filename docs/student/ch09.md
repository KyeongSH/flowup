# 9장. 문제 해결 및 자주 묻는 질문

## 9.1 자주 발생하는 문제

| 증상 | 먼저 확인할 것 | 해결 방법 |
| --- | --- | --- |
| 로그인이 안 됩니다 | 대·소문자, Caps Lock, 발급 계정 여부 | 비밀번호 재입력 → 담당 매니저 문의 |
| 내 과정이 보이지 않아요 | 수강 신청 완료 여부 | 담당 매니저에게 등록 상태 확인 |
| Zoom 링크가 안 열려요 | Zoom 앱 설치, 링크 유효성 | Zoom 앱 재설치 후 재접속 |
| 녹화영상이 재생되지 않아요 | 비밀번호 안내 확인, 저장기간 | 공지 확인 → 강사·매니저 문의 |
| 수업자료 다운로드가 안 돼요 | 브라우저 팝업 차단 | 차단 해제 후 재시도 |
| 글이 등록되지 않아요 | 제목·내용 입력 여부 | 필수 항목 입력 후 재시도 |

## 9.2 자주 묻는 질문 (FAQ)

### Q1. 처음 로그인할 때 비밀번호는 무엇인가요?

이젠아카데미에서 개별 안내한 **초기 비밀번호**를 사용합니다. 안내를 받지 못한 경우 담당 운영 매니저에게 문의합니다.

### Q2. 수업에 참석하지 못했습니다. 어떻게 하나요?

클래스룸의 '콘텐츠' 탭에서 **Zoom 녹화영상**을 확인하고 시청합니다. 결석 사유가 있는 경우 담당 매니저에게 사전·사후 안내합니다.

### Q3. 자료를 저장하고 싶은데, 외부 공유해도 되나요?

**안 됩니다.** 수업자료·녹화영상은 저작권이 있으며, 본인 학습 목적으로만 사용해야 합니다.

### Q4. 커뮤니티에서 다른 훈련생을 개인 연락처로 초대해도 되나요?

본인 판단이지만, **개인정보 요청·공유는 커뮤니티 규정 위반**이 될 수 있습니다. 학습과 관련된 소통은 커뮤니티에서 진행합니다.

### Q5. 질문을 올렸는데 답이 안 옵니다.

일반적으로 24시간 이내에 답변이 등록됩니다. 늦어지는 경우 **제목에 [질문]을 붙여 재게시**하거나 담당 강사에게 알립니다.

### Q6. 로그아웃은 어떻게 하나요?

화면 우측 상단의 이름 또는 프로필 아이콘을 선택하고 '로그아웃'을 선택합니다. 공용 PC 사용 시 반드시 로그아웃합니다.

### Q7. 여러 과정을 동시에 수강하고 있어요.

수강 과정 목록에서 원하는 과정을 선택하여 이동합니다. 로그아웃할 필요는 없습니다.

### Q8. 종강 후에도 자료를 볼 수 있나요?

일반적으로 종강 후 일정 기간 조회 가능하지만, **보관 기간은 정책에 따라 다릅니다**. 필요한 자료는 종강 전에 본인 학습 목적으로 저장하세요. `기간 확인 필요`
