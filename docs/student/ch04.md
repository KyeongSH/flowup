# 4장. 공지사항 확인

#### 왜 매일 확인해야 하나요?

수업 시간 변경, 과제 마감 안내, 중요 안내가 **공지사항으로 전달**됩니다. 매일 최소 1회 확인을 권장합니다.

#### 확인 방법

1. 클래스룸에서 '공지' 탭을 선택합니다.
2. 새 공지가 있는지 확인합니다. (등록일 기준 최신순 정렬)
3. 제목을 선택하여 내용을 확인합니다.

{% hint style="info" %}
🖼️ **[그림 4-1 삽입 위치] 공지사항 목록·상세 화면**<br>공지 리스트 · 새 공지 표시 · 상세 열람
{% endhint %}

{% hint style="warning" %}
**주의** 공지 내용을 확인하지 않아 발생하는 불이익(수업 미참여, 과제 미제출 등)은 본인 책임일 수 있습니다.
{% endhint %}
