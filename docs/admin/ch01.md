# 1장. 플로우업 개요

## 1.1 플로우업의 목적

플로우업(FLOWUP)은 이젠아카데미에서 운영하는 **직업훈련 통합 관리 플랫폼**입니다. 교육과정 개설부터 훈련생 모집, 클래스룸 운영, 콘텐츠 관리, 훈련 종료 후 자료 보관까지 전 과정을 단일 시스템에서 처리할 수 있도록 지원합니다.

## 1.2 주요 사용자

| 구분 | 역할 | 주요 사용 메뉴 |
| --- | --- | --- |
| 총괄 관리자 | 시스템 전체 운영 관리, 권한 부여 | 전체 메뉴 |
| 운영 담당자 | 과정 개설, 훈련생·강사 배정, 커뮤니티 관리 | 강의, 학생, 강사, 클래스룸 |
| 행정 담당자 | 훈련생 등록, 출결·수료 처리, 자료 다운로드 | 학생, TODO, 콘텐츠 |
| 교강사 | 담당 과정 수업 운영, 자료 등록, 공지 | 클래스룸, 콘텐츠, 커뮤니티 |
| 취업지원 담당자 | 수료생 정보 조회, 사후 관리 | 학생, 콘텐츠 |

## 1.3 관리자 사이트 접속 정보

- **접속 주소:** `https://admin.ezengn.flowup.co.kr/`
- **권장 브라우저:** Chrome, Edge 최신 버전 (Internet Explorer 미지원)
- **권장 해상도:** 1440×900 이상
- **접속 계정:** 담당자 확인 필요 `담당자 확인 필요`

{% hint style="danger" %}
**필수** 관리자 계정은 개인별로 발급되며 공유·양도할 수 없습니다. 인수인계 시 반드시 기존 계정 회수 및 신규 계정 발급 절차를 거쳐야 합니다.
{% endhint %}

## 1.4 개인정보 보호 주의사항

{% hint style="warning" %}
**주의**

- 훈련생·강사의 이름·연락처·이메일·주민등록번호·계좌정보는 **업무 목적 외 조회·다운로드 금지**
- 화면 캡처·문서 공유 시 **개인정보 마스킹 필수**
- 퇴근 시 반드시 **로그아웃** 및 화면 잠금
- 공용 PC에서 로그인 후 자동 로그인·비밀번호 저장 기능 사용 금지
{% endhint %}
