# 9장. 과정 TODO 관리

## 9.1 TODO의 목적

과정 운영에 필요한 업무를 단계별로 관리하고, 담당자·마감일·상태를 명확히 하여 **누락 없는 과정 운영**을 지원합니다.

## 9.2 신규 TODO 등록

1. 과정 상세 화면에서 'TODO' 탭 또는 대시보드 TODO 영역으로 이동합니다.
2. '+ 새 TODO' 버튼을 선택합니다.
3. 제목·내용·담당자·마감일을 입력합니다.
4. '등록' 버튼을 선택합니다.

## 9.3 상태값 및 관리 방법

| 상태 | 의미 | 사용 시점 |
| --- | --- | --- |
| `대기` | 등록됐지만 시작 전 | 업무 등록 직후 |
| `진행 중` | 현재 진행 중 | 담당자 착수 시점 |
| `완료` | 업무 완료 | 결과물 확인 후 |
| `보류` | 일시 중단 | 외부 대기·조건 미충족 |

{% hint style="danger" %}
**필수** 과정 종료 전 반드시 **미완료 TODO 잔여 여부를 점검**합니다. 미완료 상태로 남을 경우 사후 감사 시 문제가 될 수 있습니다.
{% endhint %}
