# 12장. 오류 대응 및 자주 묻는 질문

## 12.1 자주 발생하는 오류와 해결 방법

| 증상 | 예상 원인 | 확인 방법 | 해결 방법 | 문의 대상 |
| --- | --- | --- | --- | --- |
| 로그인이 되지 않음 | 계정 잠금·비밀번호 오류 | Caps Lock, 오입력 5회 여부 | 비밀번호 재설정 요청 | 총괄 관리자 / 플로우업 지원 |
| 메뉴가 보이지 않음 | 권한 미부여 | 다른 담당자 화면과 비교 | 권한 요청 | 총괄 관리자 |
| 과정이 조회되지 않음 | 검색조건·상태 필터 누락 | 필터 초기화 후 재검색 | 전체 상태로 재검색 | 운영 담당자 |
| 학생/강사가 검색되지 않음 | 등록 미완료·오탈자 | 부분 검색어로 재조회 | 신규 등록 여부 확인 후 등록 | 행정 담당자 |
| 중복 등록 메시지 | 기존 등록 존재 | 기존 학생 상세 확인 | 과정 배정으로 변경 | 행정 담당자 |
| 저장 버튼이 작동하지 않음 | 필수 항목 미입력 | 붉은 표시 필드 확인 | 필수 항목 입력 후 재시도 | 본인 재시도 |
| 콘텐츠 링크가 열리지 않음 | URL 오입력·접근권한 | 브라우저 시크릿 모드 시도 | 링크 수정 또는 재발행 | 등록 담당자 |
| Zoom 영상에 접근 불가 | 비밀번호 미포함 링크·저장기간 만료 | Zoom 클라우드 확인 | 비밀번호 포함 링크 재등록 | 강사 / 운영 담당자 |
| 권한 부족 메시지 | 기능별 권한 미부여 | 메뉴 접근 로그 확인 | 권한 신청 | 총괄 관리자 |
| 수정한 내용이 반영되지 않음 | 저장 미완료·캐시 | 새로고침(F5) 후 재확인 | 재저장, 캐시 삭제 | 본인 재시도 |

## 12.2 자주 묻는 질문 (FAQ)

### Q1. 모집 중 과정과 훈련 중 과정은 어떻게 구분하나요?

과정의 훈련기간 시작일 이전은 '모집 중', 시작일 이후 종료일 이전은 '훈련 중', 종료일 이후는 '종료' 상태로 자동 구분됩니다. 상세 상태값은 시스템 화면 확인 필요.

### Q2. 학생을 잘못된 과정에 등록했을 때 어떻게 처리하나요?

학생 상세 화면에서 '배정 과정'을 올바른 과정으로 변경합니다. 이미 훈련이 시작된 경우 **출결·수업참여 기록에 영향**이 있으므로 행정 담당자와 반드시 협의합니다.

### Q3. 강사를 여러 과정에 배정할 수 있나요?

강사 상세 화면의 '담당 과정' 영역에서 복수 과정 배정이 가능합니다. `실제 지원 여부 확인 필요`

### Q4. Zoom 녹화영상은 어디에 등록하나요?

해당 과정의 클래스룸 → '콘텐츠' 탭 → '+ 콘텐츠 등록' → 유형 'Zoom 녹화영상' 선택 후 링크를 입력합니다.

### Q5. 게시물을 삭제하면 복구할 수 있나요?

일반적으로 삭제된 게시물은 **복구가 불가**합니다. 삭제 전 반드시 백업이 필요한지 확인합니다.

### Q6. 과정 TODO의 '보류' 상태는 언제 사용하나요?

외부 승인 대기, 자료 확보 지연 등 **담당자가 조치할 수 없는 이유**로 업무를 진행할 수 없을 때 사용합니다. 보류 사유를 반드시 기록합니다.

### Q7. 과정 종료 후에도 클래스룸을 확인할 수 있나요?

종료된 과정의 클래스룸은 조회 목적으로 접근 가능합니다. 단, 편집·자료 추가 등의 기능이 제한될 수 있습니다. `확인 필요`

### Q8. 메뉴가 보이지 않을 때 누구에게 문의하나요?

먼저 다른 담당자 화면과 비교하여 권한 문제인지 확인 후, **총괄 관리자**에게 권한 부여를 요청합니다.

### Q9. 개인정보를 다운로드해야 하는 상황에는 어떻게 하나요?

업무 목적과 근거를 명확히 하고, 다운로드한 파일은 즉시 **암호화 또는 비밀번호 설정**합니다. 업무 종료 후에는 반드시 삭제합니다.

### Q10. 훈련기간을 잘못 등록했을 때 수정할 수 있나요?

과정 상세에서 수정 가능하지만, **이미 등록된 훈련생·수업자료·정산에 영향**을 줄 수 있습니다. 수정 전 반드시 행정 담당자와 협의합니다.

### Q11. 강사 계정이 있는데 클래스룸에 접속되지 않아요.

담당 과정 배정 여부를 확인합니다. 배정되지 않은 과정의 클래스룸은 접근할 수 없습니다.

### Q12. 커뮤니티 게시물에 파일을 첨부할 수 있나요?

`지원 여부 및 파일 크기 제한 확인 필요`

### Q13. 훈련생이 로그인을 못 한다고 문의합니다. 어떻게 해야 하나요?

훈련생의 아이디·비밀번호 발급 여부와 등록 상태(수강 중)를 확인합니다. 비밀번호 초기화가 필요한 경우 담당자를 통해 재설정합니다.

### Q14. 콘텐츠에 등록한 링크가 만료되었어요.

기존 링크를 삭제하지 말고 '수정' 기능으로 새 링크를 갱신합니다. 훈련생 열람 기록이 유지됩니다. `동작 확인 필요`

### Q15. 매뉴얼에 없는 기능이 시스템에 있을 때 어떻게 하나요?

임의로 기능을 사용하기 전에 총괄 관리자 또는 플로우업 지원팀에 문의하여 정확한 사용 방법을 확인합니다.
