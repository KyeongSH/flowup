# 2장. 로그인 및 기본 화면

## 2.1 관리자 사이트 접속

1. 웹 브라우저 주소창에 `https://admin.ezengn.flowup.co.kr/` 를 입력합니다.
2. 로그인 화면이 표시되면 아이디와 비밀번호를 입력합니다.
3. '로그인' 버튼을 선택합니다.

{% hint style="info" %}
🖼️ **[그림 2-1 삽입 위치] 플로우업 관리자 로그인 화면**<br>**아이디 입력창** · **비밀번호 입력창** · **로그인 버튼** 강조 표시<br> ※ 실제 로그인 화면 캡처 후 삽입 (개인 계정정보는 모자이크 처리)
{% endhint %}

## 2.2 로그인 오류 발생 시 확인사항

| 증상 | 확인사항 |
| --- | --- |
| 아이디 또는 비밀번호가 일치하지 않습니다 | 대·소문자, 한/영 전환, Caps Lock 상태 확인 |
| 비밀번호 5회 이상 오류 | 계정 잠금 가능성 → 담당자 확인 필요 |
| 페이지가 열리지 않음 | 네트워크 연결 상태 및 사내 방화벽 확인 |
| 권한이 없다는 메시지 | 계정 권한 발급 여부 담당자 확인 필요 |

## 2.3 관리자 대시보드 기본 구성

{% hint style="info" %}
🖼️ **[그림 2-2 삽입 위치] 관리자 대시보드 전체 화면**<br>① 좌측 메뉴 영역 · ② 상단 요약 통계 · ③ 최근 개강과정 리스트 · ④ 과정 TODO · ⑤ 커뮤니티/콘텐츠

## 2.4 로그아웃 및 세션 관리

1. 화면 우측 상단의 계정 아이콘(또는 사용자 이름)을 선택합니다.
2. 드롭다운 메뉴에서 '로그아웃'을 선택합니다. `위치 확인 필요`
3. 로그인 화면으로 돌아가면 정상 로그아웃 완료입니다.

{% hint style="warning" %}
**주의** 일정 시간 이상 미사용 시 자동 세션 종료됩니다. 작성 중이던 내용이 저장되지 않을 수 있으므로 **중요 작업은 수시로 저장**합니다. (자동 종료 시간 `담당자 확인 필요` )
{% endhint %}
