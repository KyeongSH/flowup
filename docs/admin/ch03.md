# 3장. 관리자 대시보드

## 3.1 요약 통계 영역

로그인 직후 표시되는 대시보드 상단에는 시스템 전체 현황이 숫자로 표시됩니다. 매일 업무 시작 시 확인하는 것을 권장합니다.

{% hint style="info" %}
🖼️ **[그림 3-1 삽입 위치] 대시보드 요약 통계 영역**<br>등록된 강의 / 모집 중 강의 / 훈련 중 강의 / 등록된 학생 수 / 등록된 강사 수 카드 위치 강조
{% endhint %}

| 항목 | 의미 | 확인 시점 |
| --- | --- | --- |
| 등록된 강의 | 시스템에 등록된 전체 과정 수 | 수시 |
| 모집 중 강의 | 현재 훈련생을 모집 중인 과정 수 | 매일 오전 |
| 훈련 중 강의 | 개강하여 훈련이 진행 중인 과정 수 | 매일 오전 |
| 등록된 학생 수 | 시스템에 등록된 전체 훈련생 누적 수 | 주 1회 |
| 등록된 강사 수 | 시스템에 등록된 전체 강사 누적 수 | 월 1회 |

## 3.2 최근 개강과정 확인

최근 개강한 과정 목록에는 다음 정보가 표시됩니다: 강의명, 회차, 훈련기간, 모집인원, 등록인원, 훈련일수. 개강 직후 **모집인원과 등록인원의 차이**를 확인하는 것이 중요합니다.

{% hint style="info" %}
🖼️ **[그림 3-2 삽입 위치] 최근 개강과정 리스트**<br>강의명 · 회차 · 훈련기간 · 모집/등록인원 · 훈련일수 컬럼
{% endhint %}

## 3.3 과정 TODO 상태 확인

대시보드에서 각 과정의 TODO 상태를 4단계로 확인할 수 있습니다.

| 상태 | 의미 | 대응 |
| --- | --- | --- |
| `대기` | 등록되었으나 아직 착수하지 않은 업무 | 담당자 배정 및 시작 |
| `진행 중` | 현재 진행 중인 업무 | 주기적 진행 확인 |
| `완료` | 완료 처리된 업무 | 결과물 확인 |
| `보류` | 일시 중단된 업무 | 보류 사유 및 재개 일정 확인 |

## 3.4 최근 커뮤니티 게시물
