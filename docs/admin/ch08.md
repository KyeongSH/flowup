# 8장. 콘텐츠 관리

## 8.1 콘텐츠 유형

| 유형 | 용도 | 등록 방법 |
| --- | --- | --- |
| Zoom 녹화영상 | 실시간 수업 녹화본 제공 | Zoom 공유 링크 등록 |
| YouTube 영상 | 참고 자료·강의 보충 | YouTube URL 등록 |
| 외부 링크 | 참고 사이트 · 문서 | URL 등록 |
| 기타 파일 | PDF · 이미지 등 | 파일 업로드 `확인 필요` |

## 8.2 Zoom 녹화영상 등록

1. Zoom 클라우드에서 녹화 파일의 공유 링크를 복사합니다.
2. 클래스룸 → '콘텐츠' 탭 → '+ 콘텐츠 등록' 버튼을 선택합니다.
3. 유형에서 'Zoom 녹화영상'을 선택합니다.
4. 제목(수업 회차·주제)과 링크를 입력합니다.
5. '등록' 버튼을 선택합니다.
6. 등록 후 **링크가 정상적으로 열리는지 반드시 확인**합니다.

{% hint style="warning" %}
**주의**

- Zoom 링크는 **비밀번호가 포함된 링크**여야 훈련생이 열람할 수 있습니다.
- Zoom 클라우드는 **저장 기간이 제한**됩니다. 장기 보관이 필요한 자료는 별도 다운로드 후 보관합니다.
{% endhint %}

## 8.3 YouTube 영상 등록

1. YouTube 영상 페이지에서 '공유' → URL을 복사합니다.
2. 콘텐츠 등록 화면에서 유형 'YouTube'를 선택합니다.
3. 제목과 URL을 입력합니다.
4. '등록' 버튼을 선택합니다.

## 8.4 콘텐츠 수정·삭제

콘텐츠 목록에서 대상 항목을 선택 후 '수정' 또는 '삭제' 버튼을 선택합니다. 삭제 시 **복구가 불가**하므로 신중히 진행합니다.
