# 11장. 시기별 운영 체크리스트

## 11.1 개강 전 체크리스트

- [ ] 과정정보 등록 (과정명·회차·훈련기간) — *운영 담당자*
- [ ] 모집인원 설정 및 실제 등록인원 확인 — *운영 담당자*
- [ ] 담당 강사 배정 및 계정 발급 — *총괄 관리자*
- [ ] 훈련생 등록 및 과정 배정 — *행정 담당자*
- [ ] 클래스룸 개설 확인 — *운영 담당자*
- [ ] 커뮤니티 채널 구성 — *운영 담당자 · 강사*
- [ ] 개강 안내 공지 등록 — *운영 담당자*
