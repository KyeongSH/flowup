# 4장. 강의·교육과정 관리

## 4.1 전체 강의 조회

#### 기능 목적

시스템에 등록된 모든 교육과정을 조회하고, 상태별·기간별로 검색합니다. 과정 운영의 시작점이 되는 화면입니다.

#### 사용 대상

운영 담당자, 총괄 관리자

#### 접근 경로

> 📍 **접근 경로:** 관리자 대시보드 → 강의관리 → 전체 강의 `경로 확인 필요`

#### 진행 순서

1. 좌측 메뉴에서 '강의관리'를 선택합니다.
2. 하위 메뉴에서 '전체 강의'를 선택합니다.
3. 검색 조건(과정명, 상태, 기간)을 입력합니다.
4. '검색' 버튼을 선택합니다.
5. 조회된 목록에서 원하는 과정을 선택하여 상세정보를 확인합니다.

{% hint style="info" %}
🖼️ **[그림 4-1 삽입 위치] 전체 강의 목록 화면**<br>**① 과정 검색** → **② 대상 과정 선택** → **③ 과정 상세정보 확인**
{% endhint %}

## 4.2 신규 과정 등록

#### 기능 목적

신규 교육과정을 시스템에 등록합니다. 훈련기간·회차·모집인원 등 기본정보를 설정하고, 개강 전 강사·훈련생 배정의 기준이 됩니다.

#### 접근 경로

> 📍 **접근 경로:** 강의관리 → 전체 강의 → '+ 신규 등록' 버튼 `버튼명 확인 필요`

#### 입력 항목

| 항목명 | 필수 여부 | 입력 방법 | 입력 예시 | 주의사항 |
| --- | --- | --- | --- | --- |
| 과정명 | `필수` | 직접 입력 | 웹풀스택 개발자 양성과정 | NCS 승인 명칭과 일치 |
| 회차 | `필수` | 숫자 입력 | 3 | 중복 회차 확인 |
| 훈련기간 | `필수` | 날짜 선택 | 2026-10-01 ~ 2027-03-31 | 공휴일·주말 반영 여부 확인 |
| 훈련일수 | `필수` | 숫자 입력 | 120일 | 실제 훈련일 기준 |
| 모집인원 | `필수` | 숫자 입력 | 25명 | NCS 승인 인원 이내 |
| 과정 유형 | `필수` | 드롭다운 선택 | K-디지털 트레이닝 | - |
| 담당 강사 | `선택` | 강사 검색·선택 | 홍** | 추후 배정 가능 |
| 과정 소개 | `선택` | 텍스트 입력 | - | - |

{% hint style="danger" %}
**필수** 위 입력 항목은 실제 시스템 화면 확인 후 정확한 필드명·필수 여부로 업데이트해야 합니다. `담당자 확인 필요`
{% endhint %}

{% hint style="info" %}
🖼️ **[그림 4-2 삽입 위치] 신규 과정 등록 화면**<br>입력 필드 영역 파란 박스 · 저장 버튼 빨간 박스 강조
{% endhint %}

#### 처리 결과

정상 저장 시 '등록되었습니다' 메시지가 표시되고, 전체 강의 목록에 해당 과정이 추가됩니다.

#### 주의사항

{% hint style="warning" %}
**주의**

- 훈련기간·회차는 등록 후 변경 시 **이미 등록된 훈련생·강사·수업자료에 영향**을 줄 수 있습니다.
- 모집인원은 실제 등록 가능 인원의 상한이므로 신중하게 입력합니다.
- 과정 유형은 저장 후 변경이 제한될 수 있습니다. `담당자 확인 필요`
{% endhint %}

## 4.3 모집 중·훈련 중 과정 조회

1. '강의관리 → 모집 중 강의' 또는 '훈련 중 강의' 메뉴를 선택합니다.
2. 조회된 목록에서 상태(모집 중 / 훈련 중 / 종료)를 확인합니다.
3. 필요 시 과정명을 선택하여 상세정보로 이동합니다.

## 4.4 과정정보 수정

1. 전체 강의 목록에서 수정할 과정을 선택합니다.
2. 상세정보 화면에서 '수정' 버튼을 선택합니다.
3. 변경할 항목을 수정합니다.
4. '저장' 버튼을 선택합니다.

{% hint style="warning" %}
**주의** 훈련기간·모집인원 등 **핵심 정보의 수정은 관계기관 신고 사항일 수 있습니다.** 수정 전 행정 담당자와 협의합니다.
{% endhint %}

## 4.5 과정 상태 변경 · 삭제

{% hint style="danger" %}
**필수** 과정 삭제는 **복구가 불가능**합니다. 삭제 대신 '비활성화' 또는 '종료' 상태로 변경하는 것을 권장합니다. 삭제 권한은 총괄 관리자에게만 부여됩니다. `권한 확인 필요`
{% endhint %}
