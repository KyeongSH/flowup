# 7장. 클래스룸 운영

## 7.1 과정별 클래스룸 접속

1. 전체 강의 목록에서 대상 과정을 선택합니다.
2. 과정 상세 화면에서 '클래스룸 이동' 버튼을 선택합니다. `버튼명 확인 필요`
3. 해당 과정의 클래스룸 메인 화면이 표시됩니다.

{% hint style="info" %}
🖼️ **[그림 7-1 삽입 위치] 과정별 클래스룸 메인 화면**<br>참여자 · 공지 · 커뮤니티 · 수업자료 · 콘텐츠 탭 위치 강조
{% endhint %}

## 7.2 참여자 확인

클래스룸에 참여 중인 훈련생과 강사 목록을 확인합니다. 개강 당일 접속 여부 점검 시 활용합니다.

## 7.3 공지 등록

1. 클래스룸 상단의 '공지' 탭을 선택합니다.
2. '+ 새 공지' 버튼을 선택합니다.
3. 제목·내용을 입력합니다.
4. 중요 공지 여부, 게시 기간을 설정합니다. `옵션 확인 필요`
5. '등록' 버튼을 선택합니다.

## 7.4 커뮤니티 채널 관리

과정별로 여러 채널을 두어 자유게시판·질문답변·자료실 등으로 분리 운영할 수 있습니다.

{% hint style="info" %}
🖼️ **[그림 7-2 삽입 위치] 커뮤니티 채널 구성 화면**<br>채널 목록 · 게시물 작성/수정/삭제 버튼 강조
{% endhint %}

## 7.5 수업자료 등록

1. 클래스룸의 '수업자료' 탭을 선택합니다.
2. '+ 자료 등록' 버튼을 선택합니다.
3. 제목, 설명, 첨부파일 또는 링크를 입력합니다.
4. 공개 범위(전체 / 특정 회차)를 설정합니다. `옵션 확인 필요`
5. '등록' 버튼을 선택합니다.

{% hint style="warning" %}
**주의** 저작권이 있는 자료(도서 스캔본, 유료 강의 자료 등)는 **업로드 금지**입니다. 반드시 자체 제작 또는 허가된 자료만 등록합니다.
{% endhint %}
