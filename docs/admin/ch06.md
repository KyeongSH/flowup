# 6장. 강사 관리

## 6.1 강사 목록 조회

> 📍 **접근 경로:** 관리자 대시보드 → 강사관리 → 전체 강사

1. 좌측 메뉴에서 '강사관리'를 선택합니다.
2. 검색 조건(이름, 담당 과정, 계약 상태)을 입력합니다.
3. '검색' 버튼을 선택합니다.

{% hint style="info" %}
🖼️ **[그림 6-1 삽입 위치] 강사 목록 조회 화면**<br>검색 · 필터 · 담당 과정 표시 컬럼
{% endhint %}

## 6.2 신규 강사 등록

| 항목명 | 필수 여부 | 주의사항 |
| --- | --- | --- |
| 이름 | `필수` | 계약서 상 이름 |
| 연락처 / 이메일 | `필수` | 계정 발급용 |
| 담당 과정 | `선택` | 복수 배정 가능 `확인 필요` |
| 강사 권한 | `필수` | 클래스룸 접근 범위 결정 |
| 경력·전공 등 | `선택` | - |

## 6.3 담당 과정 배정 및 변경

1. 강사 상세 화면에서 '담당 과정' 영역으로 이동합니다.
2. '과정 추가' 버튼을 선택합니다.
3. 과정을 검색하여 선택합니다.
4. '저장' 버튼을 선택합니다.

## 6.4 퇴사·계약 종료 처리

{% hint style="warning" %}
**주의** 강사 삭제 시 기존에 등록한 **수업자료·게시물·콘텐츠의 소유권이 어떻게 처리되는지 사전 확인** 후 진행합니다. 삭제보다 '비활성화' 처리를 권장합니다. `담당자 확인 필요`
{% endhint %}
