# 5장. 학생 관리

## 5.1 학생 목록 조회

#### 접근 경로

> 📍 **접근 경로:** 관리자 대시보드 → 학생관리 → 전체 학생

1. 좌측 메뉴에서 '학생관리'를 선택합니다.
2. 검색 조건(이름, 아이디, 과정, 상태)을 입력합니다.
3. '검색' 버튼을 선택하여 목록을 조회합니다.

{% hint style="info" %}
🖼️ **[그림 5-1 삽입 위치] 학생 목록 조회 화면**<br>검색 조건 영역(파란 박스) · 목록 컬럼 · 상세 진입 버튼(빨간 박스) · 개인정보 모자이크 처리 필수
{% endhint %}

## 5.2 신규 학생 등록

#### 입력 항목

| 항목명 | 필수 여부 | 입력 방법 | 주의사항 |
| --- | --- | --- | --- |
| 이름 | `필수` | 직접 입력 | 주민등록상 이름 |
| 생년월일 | `필수` | 날짜 선택 | 개인정보 취급 |
| 연락처 | `필수` | 숫자 입력 | 본인 명의 확인 |
| 이메일 | `필수` | 직접 입력 | 로그인 계정 발급용 |
| 배정 과정 | `필수` | 드롭다운 선택 | 중복 배정 확인 |
| 기타 개인정보 | `선택` | - | `담당자 확인 필요` |

## 5.3 과정 배정 및 수강 상태 관리

| 상태값 | 의미 | 처리 시점 |
| --- | --- | --- |
| 수강 중 | 정상 수강 상태 | 개강 후 |
| 중도탈락 | 훈련 종료 전 하차 | 사유 발생 즉시 |
| 수료 | 훈련 정상 완료 | 종강 후 |
| 미수료 | 출석·평가 미달 | 종강 후 |

{% hint style="warning" %}
**주의** 중도탈락·수료 처리는 **관계기관 보고 및 정산과 직결**됩니다. 반드시 근거 문서를 확보한 후 상태를 변경합니다.
{% endhint %}

## 5.4 개인정보 취급 주의사항

{% hint style="danger" %}
**필수**

- 학생정보 조회·다운로드 시 **업무 목적을 명확히** 하고, 개인정보 이용 기록을 남깁니다.
- 다운로드한 파일은 즉시 **암호화·비밀번호 설정**합니다.
- 업무 종료 후 다운로드 파일은 **즉시 삭제**합니다.
- 화면 캡처·문서 공유 시 개인정보는 반드시 마스킹합니다.
{% endhint %}
