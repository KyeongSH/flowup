🌱 훈련생 초기 설정 퀵 가이드 – 플로우업

최종 수정 · 2026-09-18 대상 · 수강 중인 훈련생 소요 시간 · 약 15분

이젠아카데미에서 함께하게 되어 반갑습니다! 🎉

본 가이드는 처음 시스템을 접하는 훈련생 여러분이 로그인부터 수업 참여, 자료 다운로드, 질문·소통까지 학습에 필요한 모든 기능을 빠르게 익힐 수 있도록 구성되었습니다.

지금 바로 안내를 따라 학습 여정을 시작해 보세요. 📚

1.플로우업 접속 및 로그인

이젠아카데미에서 안내받은 접속 주소와 계정으로 안전하게 로그인하세요. 로그인 상세 안내

  1. 접속 주소 입력 · 웹 브라우저(Chrome 권장)에서 ezengn.flowup.co.kr 접속
    ※ 정확한 훈련생 접속 주소는 담당 운영 매니저 확인 필요
  2. 계정 로그인 · 아카데미에서 발급받은 아이디·비밀번호 입력
  3. 비밀번호 변경 · 최초 로그인 시 새 비밀번호로 변경 후 이용
브라우저 즐겨찾기에 접속 주소를 저장하고, 매일 학습 시작 시 편하게 접속하세요.
그림 1-1
훈련생 로그인 화면
아이디·비밀번호 입력창 · 로그인 버튼 강조 표시

🔐 비밀번호를 잊어버렸을 때

  1. 로그인 화면의 [비밀번호 찾기] 선택
  2. 안내에 따라 본인 확인 진행
  3. 재발급이 안 되는 경우 담당 운영 매니저에게 문의

2.내 과정(클래스룸) 접속

로그인하면 본인이 수강 중인 과정 목록이 표시됩니다. 학습할 과정을 선택하여 클래스룸에 입장하세요. 클래스룸 이용법

STEP 1수강 과정 목록 확인
  • 여러 과정을 수강 중인 경우 목록에서 선택
  • 과정명·기간·진행률 확인
STEP 2클래스룸 입장
  1. 대상 과정 선택
  2. [클래스룸] 또는 [입장] 버튼 선택
  3. 과정별 클래스룸 화면 확인
그림 2-1
훈련생 첫 화면 · 수강 과정 목록
본인 수강 과정 카드 · 클래스룸 입장 버튼 강조

📚 클래스룸 구성 안내

영역확인할 내용
📢 공지사항매일 접속 시 가장 먼저 확인
📁 수업자료당일·이전 수업 자료 다운로드
🎬 콘텐츠Zoom 녹화영상 시청, 참고 링크 열람
💬 커뮤니티공지·질문·자유 소통

3.공지 확인 및 수업자료 다운로드

📢공지사항 매일 확인

수업 시간 변경, 과제 마감 안내, 중요 안내가 공지사항으로 전달됩니다. 매일 최소 1회 확인을 권장합니다.

  1. 클래스룸에서 [공지] 탭 선택
  2. 새 공지 확인 (최신순 정렬)
  3. 제목을 선택하여 내용 확인
공지 내용을 확인하지 않아 발생하는 불이익(수업 미참여, 과제 미제출 등)은 본인 책임일 수 있습니다.
📁수업자료 다운로드
경로 · 클래스룸 › [수업자료] 탭
  1. 수업 회차·주제로 목록 확인
  2. 필요한 자료 제목 선택
  3. 첨부파일 다운로드 또는 링크 열기
그림 3-1
수업자료 목록 화면
자료 리스트 · 다운로드 버튼 · 파일 형식 아이콘
다운로드한 자료는 본인 학습 목적으로만 사용합니다. SNS·커뮤니티·외부 사이트에 재배포하지 않으며, 강사·아카데미의 저작권을 존중합니다.

4.Zoom 수업 참여 · 녹화영상 시청

실시간 수업은 Zoom으로 진행되며, 결석하거나 복습이 필요한 경우 녹화영상을 시청할 수 있습니다. Zoom 이용 안내

STEP 1실시간 Zoom 수업 참여
  1. 수업 시작 전 [공지] 또는 [콘텐츠] 영역에서 Zoom 링크 확인
  2. Zoom 링크 선택 → Zoom 앱 실행
  3. 본인 이름(실명)으로 접속 (닉네임·별명 금지)
  4. 수업 시작 시간에 맞춰 입장
  • Zoom 접속 시 본인 이름(실명)으로 설정하지 않으면 출석 확인이 어려울 수 있습니다.
  • 수업 중 무단 녹화·화면 캡처·외부 공유는 금지됩니다.
  • 마이크·카메라 설정은 강사 안내를 따르세요.
STEP 2녹화영상 시청 (결석·복습)
경로 · 클래스룸 › [콘텐츠] 탭
  1. 시청할 회차의 Zoom 녹화영상 선택
  2. Zoom 클라우드 재생 페이지가 열립니다
  3. 안내된 비밀번호가 있으면 입력 후 재생
녹화영상은 Zoom 클라우드 저장기간이 만료되면 접근이 어려울 수 있습니다. 결석 시 가능한 빨리 시청하세요.

5.커뮤니티에 글쓰기 · 질문하기

동료 훈련생·강사와 소통하고, 학습 중 궁금한 점을 커뮤니티에 자유롭게 질문할 수 있습니다. 커뮤니티 이용법

✍️게시물 작성
경로 · 클래스룸 › [커뮤니티] 탭 › 채널 선택 › [+ 새 글]
  1. 채널(자유게시판·질문답변 등) 선택
  2. 제목·내용 입력 후 [등록]
좋은 질문 작성 팁
  • 제목에 주제를 명확히 (예: "1주차 실습 · CSS Flexbox 정렬 질문")
  • 본문에 시도한 방법과 발생한 오류·결과를 함께 기재
  • 오류 메시지·화면 캡처를 첨부하면 빠른 답변 가능
  • 본인·타인의 개인정보(이름·연락처·계정)는 포함하지 않기
그림 5-1
커뮤니티 글쓰기 화면
채널 선택 · 제목 · 본문 · 등록 버튼 강조
계정은 본인만 사용하며 대리 출석·대리 수강은 불이익 대상입니다. 커뮤니티에 타인의 개인정보나 사생활을 게시하지 않습니다.

6.학습 체크리스트

☀️매일 확인 (수업 있는 날)
  • ☐ 공지사항 새 글 확인
  • ☐ 당일 수업자료 다운로드
  • ☐ Zoom 수업 정시 참여 (실명 접속)
  • ☐ 질문 사항은 커뮤니티에 등록
📅주 1회 확인
  • ☐ 결석 회차 녹화영상 시청
  • ☐ 이번 주 수업자료 정리
  • ☐ 커뮤니티 답변·피드백 확인
🎓종강 전 확인
  • ☐ 미시청 녹화영상 확인 및 시청
  • ☐ 필요한 수업자료 저장 (본인 학습 목적)
  • ☐ 수료 관련 안내 공지 확인

7.자주 묻는 질문 (FAQ)

Q. 처음 로그인할 때 비밀번호는 무엇인가요?

이젠아카데미에서 개별 안내한 초기 비밀번호를 사용합니다. 안내를 받지 못한 경우 담당 운영 매니저에게 문의하세요.

Q. 수업에 참석하지 못했습니다. 어떻게 하나요?

클래스룸 [콘텐츠] 탭에서 Zoom 녹화영상을 시청합니다. 결석 사유가 있는 경우 담당 매니저에게 사전·사후 안내하세요.

Q. 자료를 저장하고 싶은데, 외부 공유해도 되나요?

안 됩니다. 수업자료·녹화영상은 저작권이 있으며, 본인 학습 목적으로만 사용해야 합니다.

Q. 질문을 올렸는데 답이 안 옵니다.

일반적으로 24시간 이내에 답변이 등록됩니다. 늦어지는 경우 제목에 [질문]을 붙여 재게시하거나 담당 강사에게 알리세요.

Q. 종강 후에도 자료를 볼 수 있나요?

일반적으로 종강 후 일정 기간 조회 가능하지만, 보관 기간은 정책에 따라 다릅니다. 필요한 자료는 종강 전에 저장해 두세요.
