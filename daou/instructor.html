🎓 강사 초기 설정 퀵 가이드 – 플로우업

최종 수정 · 2026-09-18 대상 · 교강사 소요 시간 · 약 20분

플로우업에 오신 것을 환영합니다!

본 가이드는 처음 시스템을 접하는 강사님들이 담당 클래스룸 접속부터 공지·수업자료 등록, Zoom 녹화영상 공유, 커뮤니티 응답까지 수업 운영에 필요한 핵심 기능을 빠르게 익힐 수 있도록 구성되었습니다.

지금 바로 안내를 따라 훈련생들과 스마트한 학습 환경을 만들어 보세요. ✨

1.플로우업 접속 및 로그인

운영팀에서 발급받은 계정으로 관리자 페이지에 접속합니다. 강사 계정 안내

  1. 접속 주소 입력 · admin.ezengn.flowup.co.kr
  2. 계정 로그인 · 운영팀에서 발급받은 아이디·비밀번호 입력
  3. 최초 비밀번호 변경 · 안내 시 새 비밀번호로 변경 후 이용
브라우저에 접속 주소를 즐겨찾기 해두면 수업 전 빠르게 클래스룸에 진입할 수 있습니다.
그림 1-1
강사 로그인 화면
아이디·비밀번호 · 로그인 버튼 강조 표시

2.담당 과정 확인 및 클래스룸 접속

강사 계정은 본인이 담당하는 과정의 클래스룸에만 접근할 수 있습니다. 로그인 후 담당 과정 목록에서 바로 클래스룸으로 이동하세요. 클래스룸 접속 방법

STEP 1담당 과정 목록 확인
경로 · 로그인 후 [담당 과정] 영역
  • 과정명 · 회차 · 훈련기간 · 등록인원 확인
  • 공동 담당 강사 여부 확인
  • 과정 상태(모집 중 / 훈련 중 / 종료) 확인
STEP 2클래스룸 진입
  1. 담당 과정 목록에서 대상 과정 선택
  2. [클래스룸 이동] 버튼 선택
  3. 클래스룸 메인 화면 확인 (공지 · 커뮤니티 · 수업자료 · 콘텐츠 · 참여자)
그림 2-1
클래스룸 메인 화면
공지 · 커뮤니티 · 수업자료 · 콘텐츠 · 참여자 탭 위치
담당 과정이 목록에 보이지 않으면 운영 담당자에게 담당 과정 배정 여부를 확인하세요. 배정되지 않은 과정의 클래스룸에는 접근할 수 없습니다.

3.공지·수업자료 등록

수업 전날 자료를 준비하고, 훈련생에게 안내가 필요한 내용은 공지로 등록합니다. 공지·수업자료 등록 상세

📢공지사항 등록
경로 · 클래스룸 › [공지] 탭 › [+ 새 공지]
  1. 제목·내용 입력 (수업 일정 변경, 과제 안내 등)
  2. 중요 공지 여부·게시 기간 설정
  3. [등록] 버튼 선택 → 목록에서 정상 등록 확인
📁수업자료 등록
경로 · 클래스룸 › [수업자료] 탭 › [+ 자료 등록]
  1. 제목 입력 — [주차·일차] · [주제] 형식 권장 (예: "1주차 2일 · HTML 기본 실습")
  2. 설명·첨부파일 등록
  3. 공개 범위 설정 후 [등록]
그림 3-1
수업자료 등록 화면
① 제목 입력 → ② 파일 첨부 → ③ 등록 버튼
저작권이 있는 자료(도서 스캔본, 유료 강의자료 등) 업로드 금지. 본인 제작 자료 또는 출처가 명확한 자료만 등록하며, 공식 링크로 대체 가능한 경우 링크를 등록합니다.

4.Zoom 녹화영상 등록

실시간 수업 후 결석생과 복습을 위해 Zoom 녹화영상을 콘텐츠로 등록합니다. Zoom 녹화영상 등록 상세

STEP 1Zoom 클라우드에서 링크 준비
  • 수업 종료 후 Zoom 클라우드에서 녹화 파일 처리 완료 확인
  • [공유] → 비밀번호 포함 링크 복사
STEP 2플로우업에 콘텐츠 등록
경로 · 클래스룸 › [콘텐츠] 탭 › [+ 콘텐츠 등록]
  1. 유형: Zoom 녹화영상 선택
  2. 제목 입력 (예: "1주차 2일 · HTML 기본 실습 · 녹화본")
  3. Zoom 공유 링크 붙여넣기
  4. [등록] 후 시크릿 창에서 재생 확인
그림 4-1
Zoom 녹화영상 등록 화면
유형 선택 · 제목 · 링크 · 등록 버튼 강조
비밀번호 없는 링크는 훈련생이 열람할 수 없습니다. Zoom 클라우드는 저장기간 제한이 있으므로, 중요한 회차는 별도 다운로드하여 백업하세요. 등록 후 만료된 링크는 삭제하지 말고 [수정]으로 갱신합니다.
YouTube 영상·외부 참고 링크도 같은 방식으로 [콘텐츠 등록]에서 유형만 다르게 선택하여 등록할 수 있습니다.

5.커뮤니티 활동 관리

과정별 커뮤니티에서 훈련생 질문에 응답하고 학습을 지원합니다. 커뮤니티 활용법

💬게시물 작성 및 응답
경로 · 클래스룸 › [커뮤니티] 탭 › 채널 선택 › [+ 새 글]
  • 질문 게시물은 24시간 이내 응답을 권장합니다.
  • 수업 시간 외 문의는 답변 시점을 예고하세요. (예: "내일 오전 답변 드리겠습니다")
  • 동일 질문이 반복되면 공지사항으로 승격하여 관리합니다.
학생의 개인정보(이름·연락처·이메일)를 커뮤니티·공지에 노출하지 않습니다. 삭제된 게시물은 복구가 불가하므로 학생 게시물 삭제 시 반드시 사유를 확인합니다.

6.수업 사이클 체크리스트

🌙수업 전날
  • ☐ 수업자료 등록 완료
  • ☐ Zoom 링크(사전 공유) 확인
  • ☐ 수업 전날 공지 게시 (일정·준비물)
☀️수업 당일
  • ☐ Zoom 시작 전 녹화 설정 확인 (필수)
  • ☐ 참여자(출석) 확인
  • ☐ 마무리 시 질의응답·다음 수업 안내
🌙수업 종료 후 (24~48시간 내)
  • ☐ Zoom 클라우드 녹화 처리 완료 확인
  • ☐ 녹화영상 콘텐츠 등록 → 시크릿 창 재생 확인
  • ☐ 커뮤니티 미답변 질문 응답
🏁종강 전
  • ☐ 전 회차 녹화영상 등록 확인
  • ☐ 수업자료 누락 확인
  • ☐ 커뮤니티 미답변 질문 정리
  • ☐ 운영 담당자에게 종강 알림

7.자주 묻는 질문 (FAQ)

Q. 여러 과정을 담당하는 경우 어떻게 전환하나요?

담당 과정 목록으로 돌아가서 다른 과정을 선택합니다. 로그아웃할 필요는 없습니다.

Q. 수업자료를 잘못 올렸어요. 삭제해도 되나요?

수업 전이라면 삭제 후 재등록해도 무방합니다. 이미 훈련생이 열람한 경우, 삭제 대신 [수정]으로 파일을 교체하고 공지로 안내합니다.

Q. Zoom 녹화영상은 언제까지 등록해야 하나요?

운영 규정에 따라 다르지만, 일반적으로 수업 종료 후 24~48시간 이내 등록을 권장합니다.

Q. 학생이 로그인이 안 된다고 문의합니다.

강사 계정에서는 학생 계정 문제를 직접 해결할 수 없습니다. 운영·행정 담당자에게 전달합니다.
