🛠️ 관리자 초기 설정 퀵 가이드 – 플로우업

최종 수정 · 2026-09-18 대상 · 운영·행정 담당자 소요 시간 · 약 30분

플로우업 관리자 페이지에 오신 것을 환영합니다!

본 가이드는 처음 시스템을 접하는 운영·행정 담당자분들이 로그인부터 과정 개설, 훈련생·강사 관리, 클래스룸 운영, 콘텐츠 등록까지 핵심 기능을 빠르게 익히고 실무에 활용할 수 있도록 구성되었습니다.

지금 바로 안내를 따라 더욱 스마트하고 효율적인 훈련 운영을 시작해 보세요. 🏢

1.플로우업 접속 및 로그인

사내 관리자로부터 공유받은 접속 URL 및 계정 정보를 통해 안전하게 접속하세요. 로그인 및 계정 설정

  1. 접속 주소 입력 : 웹 브라우저 주소창에 관리자 전용 주소 입력 (admin.ezengn.flowup.co.kr)
  2. 계정 로그인 : 부여받은 아이디와 임시 비밀번호를 입력하여 로그인
  3. 보안 설정 : 최초 로그인 시 정보 보호를 위해 새로운 비밀번호로 변경 후 서비스 이용
자주 사용하는 브라우저에 접속 주소를 [즐겨찾기] 해두면 매번 주소를 입력할 번거로움 없이 빠르게 접속할 수 있습니다.

플로우업 관리자 로그인 화면
아이디 입력창 · 비밀번호 입력창 · 로그인 버튼 강조 표시
※ 실제 화면 캡처 후 삽입 (개인 계정정보는 모자이크 처리)

🔐 권장 사용 환경

  • Chrome, Edge 최신 버전 (Internet Explorer 미지원)
  • 1440×900 이상 해상도 권장
  • 공용 PC에서는 자동 로그인·비밀번호 저장 기능 사용 금지
관리자 계정은 개인별로 발급되며 공유·양도할 수 없습니다. 인수인계 시 반드시 기존 계정 회수 및 신규 계정 발급 절차를 거쳐야 합니다.

2.대시보드 살펴보기

로그인 직후 표시되는 관리자 대시보드에서는 시스템 전체 현황을 한눈에 확인할 수 있습니다. 매일 업무 시작 시 확인하는 것을 권장합니다. 대시보드 활용법

📊요약 통계 영역

대시보드 상단에는 다음 5가지 지표가 카드 형태로 표시됩니다.

  • 등록된 강의 · 시스템 전체 등록 과정 수
  • 모집 중 강의 · 현재 훈련생을 모집 중인 과정 수
  • 훈련 중 강의 · 개강하여 훈련이 진행 중인 과정 수
  • 등록된 학생 수 · 시스템에 등록된 훈련생 누적 수
  • 등록된 강사 수 · 시스템에 등록된 강사 누적 수

3.신규 교육과정 등록 및 관리

훈련 운영의 시작점, 신규 과정을 시스템에 등록합니다. 훈련기간·회차·모집인원 등 기본정보를 설정하면 이후 강사·훈련생 배정의 기준이 됩니다. 교육과정 등록 상세

STEP 1과정 조회 및 검색
경로 · 좌측 [강의관리] App 접속 › [전체 강의] 선택
  1. 좌측 메뉴에서 '강의관리'를 선택합니다.
  2. 검색 조건(과정명, 상태, 기간)을 입력합니다.
  3. '검색' 버튼을 선택하여 목록을 조회합니다.
  4. 원하는 과정을 선택하여 상세정보를 확인합니다.
STEP 2신규 과정 등록
경로 · [강의관리] › [전체 강의] › [+ 신규 등록] 버튼 선택

4.학생·강사 관리

훈련생과 강사 정보는 각각 별도 메뉴에서 관리하며, 과정 배정을 통해 클래스룸 접근 권한이 부여됩니다. 학생·강사 등록 상세

👥학생 관리
경로 · [학생관리] › [전체 학생]
  1. 좌측 '학생관리' 메뉴 선택
  2. 검색 조건(이름·아이디·과정·상태) 입력
  3. 신규 등록 시 이름·생년월일·연락처·이메일·배정 과정 입력
  4. 저장 후 로그인 계정 발급 여부 확인

수강 상태값

상태의미처리 시점

중도탈락·수료 처리는 관계기관 보고 및 정산과 직결됩니다. 반드시 근거 문서를 확보한 후 상태를 변경합니다.
👨‍🏫강사 관리
경로 · [강사관리] › [전체 강사]
  1. 강사 목록에서 신규 등록 또는 기존 강사 선택
  2. 이름·연락처·이메일 입력 (계약서 상 이름 기준)
  3. 담당 과정 배정 — 복수 과정 배정 가능 (실제 지원 여부 확인 필요)
  4. 강사 권한 설정 후 저장
학생·강사의 개인정보는 업무 목적 외 조회·다운로드 금지이며, 다운로드 파일은 즉시 암호화하고 업무 종료 후 삭제합니다. 화면 캡처·문서 공유 시 반드시 개인정보 마스킹합니다.

5.클래스룸 운영 및 콘텐츠 관리

과정 개설 후 실제 학습이 이뤄지는 공간, 클래스룸을 개설·운영하고 수업 콘텐츠(Zoom 녹화영상, YouTube, 외부 링크)를 등록합니다. 클래스룸 운영 가이드

STEP 1클래스룸 접속
  1. 전체 강의 목록에서 대상 과정 선택
  2. 과정 상세 화면 [클래스룸 이동] 버튼 선택
  3. 클래스룸 메인 화면 확인 (공지 · 커뮤니티 · 수업자료 · 콘텐츠 · 참여자)
그림 5-1
과정별 클래스룸 메인 화면
공지 · 커뮤니티 · 수업자료 · 콘텐츠 · 참여자 탭 위치 강조
STEP 2Zoom 녹화영상 등록
  1. Zoom 클라우드에서 녹화 파일의 비밀번호 포함 공유 링크를 복사
  2. 클래스룸 [콘텐츠] 탭 → [+ 콘텐츠 등록] 선택
  3. 유형: Zoom 녹화영상 선택
  4. 제목(수업 회차·주제)과 링크 입력 후 [등록]
  5. 등록 후 시크릿 창에서 링크가 정상 재생되는지 반드시 확인
비밀번호가 포함되지 않은 링크는 훈련생이 열람할 수 없습니다. Zoom 클라우드는 저장 기간이 제한되므로, 장기 보관이 필요한 자료는 별도 다운로드 후 백업합니다.
STEP 3수업자료·공지 등록
  • 수업자료: [수업자료] 탭 → [+ 자료 등록] → 제목·설명·첨부파일 → [등록]
  • 공지사항: [공지] 탭 → [+ 새 공지] → 제목·내용·중요 여부 → [등록]
  • 커뮤니티: [커뮤니티] 탭 → 채널 선택 → [+ 새 글]
저작권이 있는 자료(도서 스캔본, 유료 강의 자료 등) 업로드 금지. 반드시 자체 제작 또는 허가된 자료만 등록합니다.

6.과정 TODO 관리

과정 운영에 필요한 업무를 단계별로 관리하여 누락 없는 훈련 운영을 지원합니다. TODO 관리 상세

📋TODO 등록 및 상태 관리
경로 · 과정 상세 › [TODO] 탭 › [+ 새 TODO]
  1. TODO 제목·내용·담당자·마감일 입력
  2. 등록 후 상태는 대기 → 진행 중 → 완료 순으로 변경
  3. 외부 대기·조건 미충족 시 보류 처리 (사유 반드시 기록)
  4. 주 1회 상태 갱신 권장
과정 종료 전 반드시 미완료 TODO 잔여 여부를 점검합니다. 미완료 상태로 남을 경우 사후 감사 시 문제가 될 수 있습니다.

7.시기별 운영 체크리스트

🚀개강 전 체크리스트
  • ☐ 과정정보 등록 (과정명·회차·훈련기간·인원)
  • ☐ 담당 강사 배정 및 계정 발급
  • ☐ 훈련생 등록 및 과정 배정
  • ☐ 클래스룸 개설 · 커뮤니티 채널 구성
  • ☐ 개강 안내 공지 등록
📚훈련 중 체크리스트 (주 1회)
  • ☐ 등록인원 및 상태(중도탈락) 확인
  • ☐ 커뮤니티 활동·질문 응대 상태 확인
  • ☐ 주간 수업자료·Zoom 녹화영상 등록 확인
  • ☐ TODO 진행 상태 갱신
🎓종강 전·후 체크리스트
  • ☐ 미완료 TODO 잔여 확인 및 처리
  • ☐ 콘텐츠 누락(회차별 녹화) 확인
  • ☐ 훈련생 최종 상태(수료·미수료) 처리
  • ☐ 과정 상태를 '종료'로 변경, 클래스룸 보관 처리

8.자주 묻는 질문 (FAQ)

Q. 모집 중 과정과 훈련 중 과정은 어떻게 구분하나요?

과정의 훈련기간 시작일 이전은 '모집 중', 시작일 이후 종료일 이전은 '훈련 중', 종료일 이후는 '종료' 상태로 자동 구분됩니다.

Q. 학생을 잘못된 과정에 등록했을 때 어떻게 처리하나요?

학생 상세에서 '배정 과정'을 올바른 과정으로 변경합니다. 훈련이 시작된 경우 출결·수업참여 기록에 영향이 있으므로 행정 담당자와 반드시 협의합니다.

Q. Zoom 링크가 만료됐을 때 어떻게 갱신하나요?

기존 콘텐츠 항목을 삭제하지 말고 [수정] 기능으로 링크만 갱신합니다. 훈련생 열람 기록이 유지됩니다.

Q. 메뉴가 보이지 않을 때 어떻게 하나요?

다른 담당자 화면과 비교하여 권한 문제인지 확인 후 총괄 관리자에게 권한 부여를 요청합니다.
