이젠아카데미 플로우업(FLOWUP) 관리자 사용 매뉴얼

CHAPTER 01플로우업 개요

1.1 플로우업의 목적

플로우업(FLOWUP)은 이젠아카데미에서 운영하는 직업훈련 통합 관리 플랫폼입니다. 교육과정 개설부터 훈련생 모집, 클래스룸 운영, 콘텐츠 관리, 훈련 종료 후 자료 보관까지 전 과정을 단일 시스템에서 처리할 수 있도록 지원합니다.

1.2 주요 사용자

구분역할주요 사용 메뉴
총괄 관리자시스템 전체 운영 관리, 권한 부여전체 메뉴
운영 담당자과정 개설, 훈련생·강사 배정, 커뮤니티 관리강의, 학생, 강사, 클래스룸
행정 담당자훈련생 등록, 출결·수료 처리, 자료 다운로드학생, TODO, 콘텐츠
교강사담당 과정 수업 운영, 자료 등록, 공지클래스룸, 콘텐츠, 커뮤니티
취업지원 담당자수료생 정보 조회, 사후 관리학생, 콘텐츠

1.3 관리자 사이트 접속 정보

  • 접속 주소: https://admin.ezengn.flowup.co.kr/
  • 권장 브라우저: Chrome, Edge 최신 버전 (Internet Explorer 미지원)
  • 권장 해상도: 1440×900 이상
  • 접속 계정: 담당자 확인 필요 담당자 확인 필요
필수 관리자 계정은 개인별로 발급되며 공유·양도할 수 없습니다. 인수인계 시 반드시 기존 계정 회수 및 신규 계정 발급 절차를 거쳐야 합니다.

1.4 개인정보 보호 주의사항

주의
  • 훈련생·강사의 이름·연락처·이메일·주민등록번호·계좌정보는 업무 목적 외 조회·다운로드 금지
  • 화면 캡처·문서 공유 시 개인정보 마스킹 필수
  • 퇴근 시 반드시 로그아웃 및 화면 잠금
  • 공용 PC에서 로그인 후 자동 로그인·비밀번호 저장 기능 사용 금지

CHAPTER 02로그인 및 기본 화면

2.1 관리자 사이트 접속

  1. 웹 브라우저 주소창에 https://admin.ezengn.flowup.co.kr/ 를 입력합니다.
  2. 로그인 화면이 표시되면 아이디와 비밀번호를 입력합니다.
  3. '로그인' 버튼을 선택합니다.

2.4 로그아웃 및 세션 관리

  1. 화면 우측 상단의 계정 아이콘(또는 사용자 이름)을 선택합니다.
  2. 드롭다운 메뉴에서 '로그아웃'을 선택합니다. 위치 확인 필요
  3. 로그인 화면으로 돌아가면 정상 로그아웃 완료입니다.
주의 일정 시간 이상 미사용 시 자동 세션 종료됩니다. 작성 중이던 내용이 저장되지 않을 수 있으므로 중요 작업은 수시로 저장합니다. (자동 종료 시간 담당자 확인 필요)

CHAPTER 03관리자 대시보드

그림 3-1
대시보드 요약 통계 영역
등록된 강의 / 모집 중 강의 / 훈련 중 강의 / 등록된 학생 수 / 등록된 강사 수 카드 위치 강조

최근 개강한 과정 목록에는 다음 정보가 표시됩니다: 강의명, 회차, 훈련기간, 모집인원, 등록인원, 훈련일수. 개강 직후 모집인원과 등록인원의 차이를 확인하는 것이 중요합니다.

그림 3-2

3.3 과정 TODO 상태 확인

대시보드에서 각 과정의 TODO 상태를 4단계로 확인할 수 있습니다.

상태의미대응
대기등록되었으나 아직 착수하지 않은 업무담당자 배정 및 시작
진행 중현재 진행 중인 업무주기적 진행 확인
완료완료 처리된 업무결과물 확인
보류일시 중단된 업무보류 사유 및 재개 일정 확인

3.4 최근 커뮤니티 게시물

강의명·채널·글 제목·작성자·작성일이 표시되어 담당 과정의 최근 활동을 빠르게 확인할 수 있습니다.

3.5 최근 등록 콘텐츠

강의명·콘텐츠 유형·제목·링크가 표시됩니다. Zoom 녹화영상, YouTube 링크 등의 등록 여부를 확인합니다.

그림 3-3

최근 게시물 리스트 · 최근 등록 콘텐츠 리스트 위치 강조

CHAPTER 04강의·교육과정 관리

4.1 전체 강의 조회

기능 목적

시스템에 등록된 모든 교육과정을 조회하고, 상태별·기간별로 검색합니다. 과정 운영의 시작점이 되는 화면입니다.

사용 대상

운영 담당자, 총괄 관리자

접근 경로

관리자 대시보드 → 강의관리 → 전체 강의 경로 확인 필요

진행 순서

  1. 좌측 메뉴에서 '강의관리'를 선택합니다.
  2. 하위 메뉴에서 '전체 강의'를 선택합니다.
  3. 검색 조건(과정명, 상태, 기간)을 입력합니다.
  4. '검색' 버튼을 선택합니다.
  5. 조회된 목록에서 원하는 과정을 선택하여 상세정보를 확인합니다.
그림 4-1
전체 강의 목록 화면
① 과정 검색 → ② 대상 과정 선택 → ③ 과정 상세정보 확인

4.2 신규 과정 등록

기능 목적

신규 교육과정을 시스템에 등록합니다. 훈련기간·회차·모집인원 등 기본정보를 설정하고, 개강 전 강사·훈련생 배정의 기준이 됩니다.

접근 경로

강의관리 → 전체 강의 → '+ 신규 등록' 버튼 버튼명 확인 필요

처리 결과

정상 저장 시 '등록되었습니다' 메시지가 표시되고, 전체 강의 목록에 해당 과정이 추가됩니다.

주의사항

주의
  • 훈련기간·회차는 등록 후 변경 시 이미 등록된 훈련생·강사·수업자료에 영향을 줄 수 있습니다.
  • 모집인원은 실제 등록 가능 인원의 상한이므로 신중하게 입력합니다.
  • 과정 유형은 저장 후 변경이 제한될 수 있습니다. 담당자 확인 필요

4.3 모집 중·훈련 중 과정 조회

  1. '강의관리 → 모집 중 강의' 또는 '훈련 중 강의' 메뉴를 선택합니다.
  2. 조회된 목록에서 상태(모집 중 / 훈련 중 / 종료)를 확인합니다.
  3. 필요 시 과정명을 선택하여 상세정보로 이동합니다.

4.4 과정정보 수정

  1. 전체 강의 목록에서 수정할 과정을 선택합니다.
  2. 상세정보 화면에서 '수정' 버튼을 선택합니다.
  3. 변경할 항목을 수정합니다.
  4. '저장' 버튼을 선택합니다.
주의 훈련기간·모집인원 등 핵심 정보의 수정은 관계기관 신고 사항일 수 있습니다. 수정 전 행정 담당자와 협의합니다.

4.5 과정 상태 변경 · 삭제

필수 과정 삭제는 복구가 불가능합니다. 삭제 대신 '비활성화' 또는 '종료' 상태로 변경하는 것을 권장합니다. 삭제 권한은 총괄 관리자에게만 부여됩니다. 권한 확인 필요

5.4 개인정보 취급 주의사항

필수

  • 다운로드한 파일은 즉시 암호화·비밀번호 설정합니다.
  • 업무 종료 후 다운로드 파일은 즉시 삭제합니다.
  • 화면 캡처·문서 공유 시 개인정보는 반드시 마스킹합니다.

12.2 자주 묻는 질문 (FAQ)

Q1. 모집 중 과정과 훈련 중 과정은 어떻게 구분하나요?

과정의 훈련기간 시작일 이전은 '모집 중', 시작일 이후 종료일 이전은 '훈련 중', 종료일 이후는 '종료' 상태로 자동 구분됩니다. 상세 상태값은 시스템 화면 확인 필요.

Q2. 학생을 잘못된 과정에 등록했을 때 어떻게 처리하나요?

학생 상세 화면에서 '배정 과정'을 올바른 과정으로 변경합니다. 이미 훈련이 시작된 경우 출결·수업참여 기록에 영향이 있으므로 행정 담당자와 반드시 협의합니다.

Q3. 강사를 여러 과정에 배정할 수 있나요?

강사 상세 화면의 '담당 과정' 영역에서 복수 과정 배정이 가능합니다. 실제 지원 여부 확인 필요

Q4. Zoom 녹화영상은 어디에 등록하나요?

해당 과정의 클래스룸 → '콘텐츠' 탭 → '+ 콘텐츠 등록' → 유형 'Zoom 녹화영상' 선택 후 링크를 입력합니다.

Q5. 게시물을 삭제하면 복구할 수 있나요?

일반적으로 삭제된 게시물은 복구가 불가합니다. 삭제 전 반드시 백업이 필요한지 확인합니다.

Q6. 과정 TODO의 '보류' 상태는 언제 사용하나요?

외부 승인 대기, 자료 확보 지연 등 담당자가 조치할 수 없는 이유로 업무를 진행할 수 없을 때 사용합니다. 보류 사유를 반드시 기록합니다.

Q7. 과정 종료 후에도 클래스룸을 확인할 수 있나요?

종료된 과정의 클래스룸은 조회 목적으로 접근 가능합니다. 단, 편집·자료 추가 등의 기능이 제한될 수 있습니다. 확인 필요

Q8. 메뉴가 보이지 않을 때 누구에게 문의하나요?

먼저 다른 담당자 화면과 비교하여 권한 문제인지 확인 후, 총괄 관리자에게 권한 부여를 요청합니다.

Q9. 개인정보를 다운로드해야 하는 상황에는 어떻게 하나요?

업무 목적과 근거를 명확히 하고, 다운로드한 파일은 즉시 암호화 또는 비밀번호 설정합니다. 업무 종료 후에는 반드시 삭제합니다.

Q10. 훈련기간을 잘못 등록했을 때 수정할 수 있나요?

과정 상세에서 수정 가능하지만, 이미 등록된 훈련생·수업자료·정산에 영향을 줄 수 있습니다. 수정 전 반드시 행정 담당자와 협의합니다.

Q11. 강사 계정이 있는데 클래스룸에 접속되지 않아요.

담당 과정 배정 여부를 확인합니다. 배정되지 않은 과정의 클래스룸은 접근할 수 없습니다.

Q12. 커뮤니티 게시물에 파일을 첨부할 수 있나요?

지원 여부 및 파일 크기 제한 확인 필요

Q13. 훈련생이 로그인을 못 한다고 문의합니다. 어떻게 해야 하나요?

훈련생의 아이디·비밀번호 발급 여부와 등록 상태(수강 중)를 확인합니다. 비밀번호 초기화가 필요한 경우 담당자를 통해 재설정합니다.

Q14. 콘텐츠에 등록한 링크가 만료되었어요.

기존 링크를 삭제하지 말고 '수정' 기능으로 새 링크를 갱신합니다. 훈련생 열람 기록이 유지됩니다. 동작 확인 필요

Q15. 매뉴얼에 없는 기능이 시스템에 있을 때 어떻게 하나요?

임의로 기능을 사용하기 전에 총괄 관리자 또는 플로우업 지원팀에 문의하여 정확한 사용 방법을 확인합니다.
