이젠아카데미 플로우업(FLOWUP) 훈련생 사용 매뉴얼

CHAPTER 01플로우업 소개

플로우업(FLOWUP)은 이젠아카데미의 온라인 학습 플랫폼입니다. 훈련 기간 동안 공지사항 확인, 수업자료 다운로드, Zoom 수업 참여, 커뮤니티 활동을 이 하나의 시스템에서 이용할 수 있습니다.

1.1 훈련생이 사용하는 주요 기능

기능이용 목적
공지사항수업 일정, 과제 안내, 중요 공지 확인
수업자료강의 PPT · 실습 파일 · 참고 자료 다운로드
Zoom 수업실시간 수업 참여, 결석 시 녹화영상 시청
커뮤니티질문, 동료와 소통, 학습 후기 공유

1.2 이용 시 주의사항

필수
  • 본인 계정은 타인과 공유하지 않습니다. 대리 출석·대리 수강은 불이익 대상입니다.
  • 수업자료·녹화영상은 본인 학습 목적으로만 사용하며, 외부에 배포하지 않습니다.
  • 커뮤니티에 다른 훈련생의 개인정보나 사생활을 게시하지 않습니다.

CHAPTER 02로그인 방법

2.1 접속 주소

웹 브라우저(Chrome 권장)에서 아래 주소로 접속합니다.

주소 https://ezengn.flowup.co.kr/
※ 관리자용(admin) 주소와 다를 수 있으며, 정확한 훈련생 접속 주소는 담당 운영 매니저에게 확인하세요. 확인 필요

2.2 로그인 순서

  1. 접속 주소에 들어갑니다.
  2. 이젠아카데미에서 발급받은 아이디와 비밀번호를 입력합니다.
  3. '로그인' 버튼을 선택합니다.
  4. 최초 로그인 시 비밀번호 변경 안내가 나오면 새 비밀번호로 변경합니다. 확인 필요
그림 2-1
훈련생 로그인 화면
아이디·비밀번호 입력창 · 로그인 버튼 강조 표시

2.3 비밀번호를 잊어버렸을 때

  1. 로그인 화면의 '비밀번호 찾기'를 선택합니다. 지원 여부 확인 필요
  2. 안내에 따라 본인 확인을 진행합니다.
  3. 비밀번호가 재발급되지 않는 경우 담당 운영 매니저에게 문의합니다.

CHAPTER 03내 과정(클래스룸) 접속

3.1 로그인 후 첫 화면

로그인하면 본인이 수강 중인 과정 목록이 표시됩니다. 여러 과정을 수강 중이라면 접속할 과정을 선택합니다.

그림 3-1
훈련생 첫 화면 · 수강 과정 목록
본인 수강 과정 카드 · 클래스룸 입장 버튼 강조

3.2 클래스룸 이동

  1. 수강 과정 목록에서 대상 과정을 선택합니다.
  2. '클래스룸' 또는 '입장' 버튼을 선택합니다. 버튼명 확인 필요
  3. 과정별 클래스룸 화면이 표시됩니다.

3.3 클래스룸 구성 안내

영역확인할 내용
공지사항매일 접속 시 가장 먼저 확인
수업자료당일·이전 수업 자료 다운로드
콘텐츠Zoom 녹화영상 시청, 참고 링크 열람
커뮤니티공지·질문·자유 소통

CHAPTER 04공지사항 확인

왜 매일 확인해야 하나요?

수업 시간 변경, 과제 마감 안내, 중요 안내가 공지사항으로 전달됩니다. 매일 최소 1회 확인을 권장합니다.

확인 방법

  1. 클래스룸에서 '공지' 탭을 선택합니다.
  2. 새 공지가 있는지 확인합니다. (등록일 기준 최신순 정렬)
  3. 제목을 선택하여 내용을 확인합니다.
그림 4-1
공지사항 목록·상세 화면
공지 리스트 · 새 공지 표시 · 상세 열람
주의 공지 내용을 확인하지 않아 발생하는 불이익(수업 미참여, 과제 미제출 등)은 본인 책임일 수 있습니다.

CHAPTER 05수업자료 다운로드

이용 방법

  1. 클래스룸에서 '수업자료' 탭을 선택합니다.
  2. 수업 회차·주제로 목록을 확인합니다.
  3. 필요한 자료의 제목을 선택합니다.
  4. 첨부파일 또는 링크를 다운로드하거나 엽니다.
그림 5-1
수업자료 목록 화면
자료 리스트 · 다운로드 버튼 · 파일 형식 아이콘
필수
  • 다운로드한 자료는 본인 학습 목적으로만 사용합니다.
  • SNS · 커뮤니티 · 외부 사이트에 재배포하지 않습니다.
  • 강사·이젠아카데미의 저작권을 존중합니다.

CHAPTER 06Zoom 수업 참여 · 녹화영상 시청

6.1 실시간 Zoom 수업 참여

  1. 수업 시작 시간 전 공지 또는 콘텐츠 영역에서 Zoom 링크를 확인합니다.
  2. Zoom 링크를 선택합니다.
  3. Zoom 앱이 실행되면 본인 이름으로 접속합니다. (닉네임·별명 사용 금지)
  4. 수업 시작 시간에 맞춰 입장합니다.
주의
  • Zoom 접속 시 본인 이름(실명)으로 설정합니다. 출석 확인이 어려울 수 있습니다.
  • 수업 중 무단 녹화·화면 캡처·외부 공유는 금지됩니다.
  • 마이크·카메라 설정은 강사의 안내를 따릅니다.

6.2 녹화영상 시청 (결석 · 복습)

  1. 클래스룸의 '콘텐츠' 탭을 선택합니다.
  2. 시청할 회차의 Zoom 녹화영상을 선택합니다.
  3. Zoom 클라우드 재생 페이지가 열립니다.
  4. 수업 자료에 안내된 비밀번호를 입력합니다. (필요 시)
참고 녹화영상은 Zoom 클라우드 저장기간이 만료되면 접근이 어려울 수 있습니다. 결석 시 가능한 빨리 시청하는 것을 권장합니다.

CHAPTER 07커뮤니티에 글쓰기 · 질문하기

7.1 게시물 작성

  1. 클래스룸의 '커뮤니티' 탭을 선택합니다.
  2. 작성할 채널(자유게시판·질문답변 등)을 선택합니다.
  3. '+ 새 글' 버튼을 선택합니다.
  4. 제목과 내용을 입력합니다.
  5. '등록' 버튼을 선택합니다.

7.2 좋은 질문 작성 팁

TIPS
  • 제목에 주제를 명확히 씁니다. 예: "1주차 실습 · CSS Flexbox 정렬 질문"
  • 본문에 시도한 방법과 발생한 오류·결과를 함께 적습니다.
  • 오류 메시지·화면 캡처를 첨부하면 빠른 답변을 받을 수 있습니다.
  • 본인·타인의 개인정보(이름·연락처·계정)는 포함하지 않습니다.
그림 7-1
커뮤니티 글쓰기 화면
채널 선택 · 제목 · 본문 · 등록 버튼 강조

7.3 댓글·답변 확인

본인이 작성한 글에 답변이 달리면 알림 또는 목록에서 확인할 수 있습니다. 알림 지원 여부 확인 필요

7.4 게시물 수정·삭제

본인 게시물은 상세 화면의 '수정'·'삭제' 버튼으로 관리할 수 있습니다. 삭제된 글은 복구할 수 없으므로 신중히 선택합니다.

CHAPTER 09문제 해결 및 자주 묻는 질문

9.1 자주 발생하는 문제

증상 먼저 확인할 것 해결 방법
로그인이 안 됩니다대·소문자, Caps Lock, 발급 계정 여부비밀번호 재입력 → 담당 매니저 문의
내 과정이 보이지 않아요수강 신청 완료 여부담당 매니저에게 등록 상태 확인
Zoom 링크가 안 열려요Zoom 앱 설치, 링크 유효성Zoom 앱 재설치 후 재접속
녹화영상이 재생되지 않아요비밀번호 안내 확인, 저장기간공지 확인 → 강사·매니저 문의
수업자료 다운로드가 안 돼요브라우저 팝업 차단차단 해제 후 재시도
글이 등록되지 않아요제목·내용 입력 여부필수 항목 입력 후 재시도

9.2 자주 묻는 질문 (FAQ)

Q1. 처음 로그인할 때 비밀번호는 무엇인가요?

이젠아카데미에서 개별 안내한 초기 비밀번호를 사용합니다. 안내를 받지 못한 경우 담당 운영 매니저에게 문의합니다.

Q2. 수업에 참석하지 못했습니다. 어떻게 하나요?

클래스룸의 '콘텐츠' 탭에서 Zoom 녹화영상을 확인하고 시청합니다. 결석 사유가 있는 경우 담당 매니저에게 사전·사후 안내합니다.

Q3. 자료를 저장하고 싶은데, 외부 공유해도 되나요?

안 됩니다. 수업자료·녹화영상은 저작권이 있으며, 본인 학습 목적으로만 사용해야 합니다.

Q4. 커뮤니티에서 다른 훈련생을 개인 연락처로 초대해도 되나요?

본인 판단이지만, 개인정보 요청·공유는 커뮤니티 규정 위반이 될 수 있습니다. 학습과 관련된 소통은 커뮤니티에서 진행합니다.

Q5. 질문을 올렸는데 답이 안 옵니다.

일반적으로 24시간 이내에 답변이 등록됩니다. 늦어지는 경우 제목에 [질문]을 붙여 재게시하거나 담당 강사에게 알립니다.

Q6. 로그아웃은 어떻게 하나요?

화면 우측 상단의 이름 또는 프로필 아이콘을 선택하고 '로그아웃'을 선택합니다. 공용 PC 사용 시 반드시 로그아웃합니다.

Q7. 여러 과정을 동시에 수강하고 있어요.

수강 과정 목록에서 원하는 과정을 선택하여 이동합니다. 로그아웃할 필요는 없습니다.

Q8. 종강 후에도 자료를 볼 수 있나요?

일반적으로 종강 후 일정 기간 조회 가능하지만, 보관 기간은 정책에 따라 다릅니다. 필요한 자료는 종강 전에 본인 학습 목적으로 저장하세요. 기간 확인 필요
