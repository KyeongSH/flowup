이젠아카데미 플로우업(FLOWUP) 강사 사용 매뉴얼

CHAPTER 01시작하기 전에

1.1 강사 계정의 권한 범위

강사 계정은 본인이 담당하는 과정의 클래스룸에만 접근할 수 있습니다. 다른 과정 및 학생·강사 관리 기능은 사용할 수 없습니다.

1.2 강사의 주요 업무

업무주요 활동주기
수업 준비수업자료 등록, 사전 공지 작성수업 전일
수업 진행Zoom 진행, 출결 확인매 수업
수업 종료 후녹화영상·자료 등록, 질의응답수업 종료 후
주간 마감주간 자료 정리, 미제출 확인주 1회
과정 종료최종 자료 확인, 미완 항목 정리종강 전
필수 학생의 개인정보(이름·연락처·이메일 등)를 외부에 공유하거나 SNS·개인 저장소에 저장하지 않습니다. 캡처·문서 공유 시 반드시 마스킹합니다.

CHAPTER 02로그인 및 기본 화면

2.1 로그인

  1. 웹 브라우저에서 https://admin.ezengn.flowup.co.kr/ 에 접속합니다.
  2. 운영팀에서 발급받은 아이디·비밀번호를 입력합니다.
  3. '로그인' 버튼을 선택합니다.
그림 2-1

아이디·비밀번호 입력창 · 로그인 버튼 강조

강사 계정으로 로그인하면 담당 과정 중심의 화면이 표시됩니다. 관리자 대시보드의 전체 통계가 아닌, 담당 클래스룸으로 바로 이동할 수 있는 영역이 제공됩니다. 실제 화면 확인 필요

그림 2-2

주의 일정 시간 미사용 시 자동 로그아웃되므로, 수업자료·게시물 작성 중에는 수시로 저장합니다.

CHAPTER 03담당 과정 확인

3.1 담당 과정 목록 조회

  1. 좌측 메뉴 또는 대시보드에서 '담당 과정' 영역을 선택합니다. 메뉴명 확인 필요
  2. 표시된 과정 목록에서 훈련기간·회차·상태를 확인합니다.
  3. 수업을 진행할 과정을 선택하여 클래스룸으로 이동합니다.

3.2 과정 정보 확인 항목

  • 과정명 및 회차
  • 훈련기간
  • 등록인원
  • 공동 담당 강사(있는 경우)
  • 과정 상태(모집 중 / 훈련 중 / 종료)
참고 담당 과정이 목록에 보이지 않는 경우, 운영 담당자에게 담당 과정 배정 여부를 확인합니다. 강사 계정에 과정이 배정되지 않으면 클래스룸에 접근할 수 없습니다.

CHAPTER 04클래스룸 운영

  2. '클래스룸 이동' 버튼을 선택합니다.
  3. 클래스룸 메인 화면이 표시됩니다.

참여자 탭에서 현재 수강 중인 훈련생 목록을 확인합니다. 명단이 실제 등록인원과 일치하지 않는 경우 운영 담당자에게 즉시 문의합니다.

CHAPTER 05공지사항 등록

기능 목적

수업 일정 변경, 과제 안내, 중요 안내를 훈련생 전체에게 전달합니다.

접근 경로

클래스룸 → 공지 탭 → '+ 새 공지'

진행 순서

  1. 클래스룸에서 '공지' 탭을 선택합니다.
  2. '+ 새 공지' 버튼을 선택합니다.
  3. 제목과 내용을 입력합니다.
  4. 중요 공지 여부·게시 기간을 설정합니다. 옵션 확인 필요
  5. '등록' 버튼을 선택합니다.
  6. 목록에서 정상 등록 여부를 확인합니다.
그림 5-1
공지사항 등록 화면
① 제목 입력 → ② 내용 입력 → ③ 등록 버튼

주의사항

주의
  • 공지 삭제 후에는 복구가 어려우므로 내용을 다시 확인 후 삭제합니다.
  • 학생 개인정보(이름·연락처)는 공지에 포함하지 않습니다.
  • 외부 링크 삽입 시 안전한 링크인지 확인합니다.

CHAPTER 06수업자료 등록

기능 목적

수업에 사용하는 강의노트, 실습 파일, 참고 문서를 훈련생에게 공유합니다.

접근 경로

클래스룸 → 수업자료 탭 → '+ 자료 등록'

진행 순서

  1. 클래스룸의 '수업자료' 탭을 선택합니다.
  2. '+ 자료 등록' 버튼을 선택합니다.
  3. 제목·설명을 입력합니다. (예: "1주차 2일 · HTML 기본 실습")
  4. 파일 첨부 또는 외부 링크를 등록합니다.
  5. 공개 범위를 설정합니다. 옵션 확인 필요
  6. '등록' 버튼을 선택합니다.
그림 6-1
수업자료 등록 화면
제목·설명 입력(파란 박스) · 파일 업로드 · 등록 버튼(빨간 박스)

제목 작성 기준 (권장)

권장
  • [회차/일차] 형식을 앞에 붙입니다. 예: "1주차 2일 · HTML 기본"
  • 주제를 한눈에 알 수 있도록 명확하게 작성합니다.
  • 파일 버전이 있는 경우 (v2), (수정본) 등을 표기합니다.

주의사항

필수
  • 저작권이 있는 자료(도서 스캔본, 유료 강의자료 등) 업로드 금지
  • 본인 제작 자료 또는 출처가 명확한 자료만 등록합니다.
  • 학생 개인정보가 포함된 자료(제출 과제 등)는 별도 관리합니다.

CHAPTER 07Zoom · YouTube 콘텐츠 등록

7.1 Zoom 녹화영상 등록

사전 준비

  • Zoom 클라우드에서 녹화 파일이 정상 처리됐는지 확인합니다.
  • '공유' → 비밀번호 포함 링크를 복사합니다.

진행 순서

  1. 클래스룸의 '콘텐츠' 탭을 선택합니다.
  2. '+ 콘텐츠 등록' 버튼을 선택합니다.
  3. 유형에서 'Zoom 녹화영상'을 선택합니다.
  4. 제목을 입력합니다. (예: "1주차 2일 · HTML 기본 실습 · 녹화본")
  5. Zoom 공유 링크를 붙여넣습니다.
  6. '등록' 버튼을 선택합니다.
  7. 등록 후 시크릿 창에서 링크를 열어 정상 재생되는지 반드시 확인합니다.
그림 7-1
Zoom 녹화영상 등록 화면
유형 선택 · 제목 · 링크 · 등록 버튼 강조
주의
  • 비밀번호 없는 링크는 훈련생이 열람할 수 없습니다.
  • Zoom 클라우드는 저장기간 제한이 있으므로, 중요한 회차는 별도 다운로드하여 백업합니다.
  • 등록한 링크가 만료된 경우, 항목을 삭제하지 말고 '수정'으로 갱신합니다.

7.2 YouTube 영상 등록

  1. YouTube 영상 페이지에서 '공유' → URL을 복사합니다.
  2. 콘텐츠 등록 화면에서 유형 'YouTube'를 선택합니다.
  3. 제목과 URL을 입력합니다.
  4. '등록' 버튼을 선택합니다.

7.3 외부 링크 등록

참고 사이트·문서 링크를 등록할 수 있습니다. 등록 후 링크가 실제로 열리는지 반드시 확인합니다. 유료·회원 전용 콘텐츠 링크는 등록에 부적합할 수 있습니다.

CHAPTER 08커뮤니티 활동 관리

8.1 커뮤니티 채널 구조

과정별로 자유게시판·질문답변·자료실 등 여러 채널이 구성될 수 있습니다. 채널 구성은 운영 담당자와 사전 협의합니다.

8.2 게시물 작성

  1. 클래스룸의 '커뮤니티' 탭을 선택합니다.
  2. 게시할 채널을 선택합니다.
  3. '+ 새 글' 버튼을 선택합니다.
  4. 제목과 내용을 입력합니다.
  5. '등록' 버튼을 선택합니다.

8.3 훈련생 질문 응대

권장
  • 질문 게시물은 24시간 이내 응답을 권장합니다.
  • 수업 시간 외 문의는 답변 시점을 예고합니다. (예: "내일 오전 답변 드리겠습니다")
  • 동일 질문이 반복될 경우 공지사항으로 승격합니다.

8.4 게시물 수정·삭제

필수 삭제된 게시물은 복구가 불가합니다. 학생의 게시물을 삭제하기 전에 반드시 삭제 사유를 확인하고, 필요 시 학생에게 사전 안내합니다.

10.2 자주 묻는 질문 (FAQ)

Q1. 여러 과정을 담당하는 경우 어떻게 전환하나요?

담당 과정 목록으로 돌아가서 다른 과정을 선택합니다. 로그아웃할 필요는 없습니다.

Q2. 수업자료를 잘못 올렸어요. 삭제해도 되나요?

수업 전이라면 삭제 후 재등록해도 무방합니다. 이미 훈련생이 열람한 경우, 삭제 대신 '수정'으로 파일을 교체하고 공지로 안내합니다.

Q3. Zoom 녹화영상은 언제까지 등록해야 하나요?

운영 규정에 따라 다르지만, 일반적으로 수업 종료 후 24~48시간 이내 등록을 권장합니다. 세부 기준은 운영 담당자에게 확인합니다.

Q4. 훈련생 개인 문의는 어디로 응답해야 하나요?

공개적으로 답변해도 될 내용은 커뮤니티에, 개인정보가 포함된 경우 1:1 채널 또는 이메일을 사용합니다. 1:1 채널 지원 여부 확인 필요

Q5. 강의 계획을 변경했을 때 어떻게 안내하나요?

공지사항에 등록하고, 필요 시 수업자료 목차도 함께 수정합니다. 큰 변경은 운영 담당자에게 사전 협의합니다.

Q6. 학생이 로그인이 안 된다고 문의합니다.

강사 계정에서는 학생 계정 문제를 직접 해결할 수 없습니다. 운영/행정 담당자에게 전달합니다.

Q7. 저작권이 있는 자료를 수업에서 소개하고 싶습니다.

업로드 대신 공식 출처 링크를 등록하고, 수업 중 화면 공유 시에도 짧게 인용하고 출처를 명확히 표기합니다.

Q8. 종강 후에도 클래스룸에 접근할 수 있나요?

일반적으로 종료 과정도 조회는 가능하지만 편집이 제한될 수 있습니다. 정확한 정책은 담당자 확인 필요
